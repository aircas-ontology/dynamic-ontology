# 实体浏览页面合并

## 需求理解

将 project-detail 的空间浏览及后续页面合并到本项目，由对象空间浏览与主题空间浏览共同使用。用户已授权直接实施；接口差异暂不处理、不新增接口对接。

## 修改范围

- 新增实体浏览、对象画像、行为浏览页面及其页面私有组件、类型、演示数据、构建期资源、工具和测试。
- 修改工作区路由、空间首页进入逻辑、对象工作区、关系工作区、函数算子工作区及布局中与浏览模式相关的部分。
- 保持当前项目既有接口和管理页面功能，不覆盖整个同名文件；不修改或新增接口契约、运行时配置、依赖及受保护目录。
- 新增本计划文件；不删除已有文件。

## 核心实现

从来源项目按需移植浏览页面、行为演示和对象画像，按照目标项目目录与命名规范调整。独立浏览路由传递空间类型与来源；切换页面、进入画像及返回时保留上下文。对象、关系和函数算子通过浏览模式隐藏管理命令，保护现有管理模式。保留来源项目的示例内容及调用测试，不接入新接口；避免将不存在的对象误显示为固定画像，也避免所有实体指向同一个外部详情。图表、地图的实例生命周期、主题和错误状态按目标规范适配。关系图采用符合页面边界的实现，不跨页面引用私有组件。

## 依赖

不新增依赖；沿用项目现有 Vue、Element Plus、ECharts、Mars3D 等。

## 验证

先编写路由、浏览模式和来源保留测试并确认目标行为未实现，再实施并运行相关行为测试。执行 npm test、npm run test:coverage、npm run check:types-conventions、npm run type-check、npm run build:verify、npm run check:project-conventions、明确文件范围的格式检查与 git diff --check；按可用环境进行浏览器冒烟验证，记录已有失败与未执行项。

- 新增路由测试先因缺少目标路由失败；实现后新增的路由、对象卡片／表格和实体行测试通过。空间入口原有测试也通过。
- 新增页面不发起接口请求，概览、行为和已知对象画像使用标注的演示数据；未知对象不回落为其他对象画像，实体详情显示未接入。现有对象、关系和函数工作区继续使用其原有数据请求。
- 样例画像没有迁入其他页面专属图片，相关图片暂不显示；未移动、删除现有图片，也未触及接口或 public 配置。
- npm test：851 项中 822 通过、29 失败，失败项与本次修改前记录的 29 项一致。两项受到路由和条件跳转影响的旧结构断言已更新。
