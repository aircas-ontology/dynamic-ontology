# Plan：AI 助手构建步骤条外置（步骤外层 + 对话框插入当前步骤下方）

- 分支：dev_sthq_1012_only
- 状态：已确认

## 需求理解

对照原型图，调整 AI 助手对象构建消息的展示结构：

1. 步骤条移到对话框外层：构建类助手消息不再使用两栏气泡（左步骤轨 + 右内容），改为全宽纵向步骤时间线。
2. 对话框（气泡：过程折叠区、正文块、选择卡片、错误、"正在回复…"占位）插入当前步骤头部下方展示。
3. 每个步骤头可点击收起/展开其下方内容区；当前步骤默认展开（数据模型上仅当前步骤有内容区，故仅当前步骤头提供收起/展开交互）。
4. 最左侧竖线纵向连接各步骤圆圈。
5. 当前步骤行右侧显示"第X步/共Y步"（原气泡内进度标签移到此处）；过程折叠区保留在对话框内，不按步骤拆分（过程日志为消息级数据，无步骤边界）。
6. 用户消息与普通问答助手消息的气泡样式不变。

## 核心实现方式

1. 模板：
   - 构建消息移除 `bubble--layout` 两栏结构，改为 `<ol class="ai-assistant-drawer__build-steps">`（保留类名与 aria-label "对象构建步骤"，最小化测试改动）。
   - 每个 `<li>`：步骤头按钮（圆圈序号 + 标题 + 右侧 meta + 展开箭头）；当前步骤的 `<div class="build-step-body">` 内渲染原气泡内容（过程 details、正文块、选择卡片、错误、占位）。
   - 右侧 meta：仅当前步骤显示"第X步/共Y步"。
2. 交互状态：
   - `collapsedBuildStepsByMessage: Record<string, number[]>`，记录被手动收起的步骤索引。
   - 步骤头点击切换当前步骤索引的收起/展开；当前步骤默认展开。
   - 当前步骤内容用 `v-show` 控制显隐，避免流式期间重建 DOM。
3. 样式：
   - 竖线：`li::after` 沿最左侧圆圈中心纵向连接，圆圈 `z-index` 与背景色遮线；末步骤不画线。
   - 展开箭头旋转过渡；双主题（`:root[theme="light"]` 分支保留）。
   - 步骤 body 内气泡宽度 100%。
4. 非构建消息（用户消息、普通问答）模板分支保持不变。

## 增量需求（2026-10-13 下午，用户确认截图后提出）

构建进行中用户追问（如回复"选择0928对象空间"）后，助手续流重新输出步骤标记，导致渲染出第二条步骤时间线。

处理方式（同组件、同测试文件范围内实施）：

1. 新增 `conversationGroups` 计算属性，将会话消息划分为构建组与普通消息组：连续的构建类助手消息合并为同一构建组；用户消息的前一条与后一条助手消息均带构建进度时归入该组。
2. 每个构建组只渲染一条时间线，进度取该组最后一条助手消息的构建进度（反映模型最新位置）；组内全部消息内容（前序助手正文 + 用户追问气泡 + 续流正文）按时间顺序渲染在当前步骤下方。
3. 用户追问在时间线内以右对齐青色气泡（`ai-assistant-drawer__bubble--user-inline`）展示；收起/展开状态按构建组（key 为组内首条助手消息 id）记录。
4. 测试断言同步更新（`conversationGroups`、`user-inline`、meta 改用 `group.progress`）。
