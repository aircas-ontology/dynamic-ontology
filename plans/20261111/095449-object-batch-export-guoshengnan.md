# 对象列表批量导出流程调整

## 需求理解
对象列表默认隐藏多选控件。点击批量导出进入选择模式，展示对象多选控件和每个分类标题的全选按钮；选择后再次点击批量导出导出选中数据。

## 修改范围
调整对象列表组件的选择状态、分类全选交互和批量导出按钮流程，保持单对象导出及浏览态不变。

## 文件
- 修改 `src/views/ObjectWorkspacePanel/components/OntologyObjectList.vue`
- 如需补充，仅修改对象列表相关测试文件

## 核心实现
增加批量导出选择模式状态；选择模式控制卡片/表格多选控件和分类标题全选按钮；首次点击进入模式，二次点击校验选择并触发现有导出事件；数据或模式变化时同步清理无效选择。
