# 需求理解

统一对象、属性和关系的必填与 API 格式校验，并在概念构建中检查重复 API 和关系连接。已有对象的 API 不可修改，数据源绑定属性不增加锁定。

# 修改范围

- 修改概念构建页面及其校验工具，增加对象、属性、关系校验、字段提示和错误定位。
- 修改对象、属性及关系创建表单，统一 API 格式校验。
- 新增共享 API 格式校验工具与本计划；修改相关测试。无依赖变化，不删除文件。

# 核心实现方式

API 仅允许字母、数字和下划线，首字符为字母或下划线。概念画布保存前检查对象及关系必填和长度、属性现有规则、连接有效性与重复 API：对象和关系分别在画布内唯一，属性在其所属对象内唯一；去首尾空格并区分大小写。保存失败时选中第一个无效节点并显示对应字段错误。已有对象锁定 API。画布和创建表单共用格式校验。

# 新增依赖

无。

# 验证方式

先编写行为测试并确认失败，再实现并运行相关测试、全量测试、覆盖率、类型检查、临时目录构建、格式和 diff 检查；可用时执行浏览器冒烟验证。
