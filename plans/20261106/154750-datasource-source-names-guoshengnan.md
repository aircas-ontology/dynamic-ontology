# 需求理解

数据源构建对象时，分别展示并提交原始数据源名称和可编辑的入库名称；外键引用编辑后的入库表名和属性名。

# 修改范围

- 修改数据源构建向导、页面和接口类型，以及对象创建请求组装。
- 修改数据源构建流程和提交测试，覆盖多表、编辑、重载、空值和外键映射。
- 新增本计划；不删除文件、不增加依赖，保留现有主键展示改动。

# 核心实现方式

第二步新增原始表名列和独立的可编辑入库表名，保留现有 APIName 字段；第三步新增原始字段名列和独立可编辑属性名，保留主键标记。初始入库名称取原始名称，返回上一步重新查询时保留编辑。提交的 `sourceTableName`、`sourceColumnName` 使用原始名称，`tableName`、`columnName` 和外键引用使用编辑后的入库名称。`displayName`、`description` 和对象 API 保持现有逻辑；只校验选中的入库表名及属性名非空。

# 新增依赖

无。

# 验证方式

先编写行为测试并确认目标行为失败，再实现。执行相关测试、全量测试、覆盖率、类型规范检查、类型检查、临时目录构建、格式及 diff 检查；可用时检查浏览器交互。
