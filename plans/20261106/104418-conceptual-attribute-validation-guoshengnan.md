# 需求理解

概念构建中的属性新增、编辑和保存应与对象属性页面的适用限制一致，保存时定位首个无效属性并提示。

# 修改范围

- 修改 `src/views/OntologyConceptualModelCreate/index.vue`，增加保存校验和主键字段限制。
- 新增概念构建页面私有属性校验工具，检查名称、API、类型、存储分组、默认值和键冲突。
- 将已有默认值校验工具迁移至 `src/utils/validateAttributeDefaultValue.ts`，调整原页面及测试引用，供两个页面复用。
- 修改画布相关测试，覆盖校验、定位、主键及保存行为；新增本计划。无文件删除以外的业务变更。
- 不增加属性分类、数据源绑定限制、API 格式或唯一性约束。

# 核心实现方式

勾选主键时设置 API 为 `id`、类型为 `Int` 并锁定字段；保存前遍历所有对象属性，检查必填、存储分组格式和默认值类型，发现问题选中属性并显示错误，不发送请求。检查重复键及已有主键字段，避免载入的异常数据绕过保存校验。

# 新增依赖

无，复用已有依赖和默认值校验。

# 验证方式

先添加行为测试并确认目标行为缺失导致失败，再实现并运行相关测试、`npm test`、`npm run test:coverage`、`npm run type-check`、`npm run build:verify`、任务文件格式检查和 diff 检查。浏览器验证受影响的保存及主键操作，无法执行时记录原因。
