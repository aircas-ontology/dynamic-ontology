# 需求理解

概念构建中编辑已有属性时，与对象属性页面一致检查数据源绑定；画布中新建对象及属性无需查询。

# 修改范围

- 修改概念构建页面，选中已有属性时查询并展示绑定状态，锁定受限字段并提供失败重试；保存前保护已变更属性。
- 新增页面私有绑定状态管理逻辑，复用现有对象属性详情接口并按对象缓存，处理并发、过期响应和卸载。
- 增加行为测试覆盖绑定、未绑定、新增、失败、重试、并发切换和保存保护；新增本计划，不删除文件。

# 核心实现方式

仅同时具有已有对象和属性标识的数据查询绑定状态；原始画布数据中缺失标识时明确报错。按对象缓存成功响应并合并重复请求，失败可重试。绑定时只允许修改名称和描述，保存前检查修改的已有属性并阻止锁定字段变更，保留画布原始数据。选择变更及卸载后忽略过期请求。

# 新增依赖

无，复用现有接口和 Vue。

# 验证方式

先添加行为测试并确认失败，再实现。执行相关测试、全量测试、覆盖率、类型检查、临时目录构建、格式及 diff 检查；可用时验证浏览器交互。
