# 属性元数据 JSON 字符串

## 需求理解

属性创建和编辑请求的 metadata 字段传 JSON 格式字符串，属性读取时兼容字符串及原有对象以供回显。

## 修改范围

修改属性请求及响应类型、属性表单请求参数与读取适配、相关测试；新增本计划文件，不删除文件。

## 核心实现方式

请求边界通过 JSON.stringify 转换元数据；读取时安全解析 JSON 对象，兼容已有对象与空值。保持表单内部对象状态。

## 新增依赖

无，使用平台 JSON 能力。

## 验证方式

先添加请求及回显行为测试并确认失败，实施后运行相关测试、项目测试和覆盖率、类型规范、类型检查、临时构建、格式及差异检查。记录现有失败和验收缺口。
