# 需求理解

用户确认：规则条件中引用多个对象时，后续行为可选项为与任意对象关联行为的合集。使用条件变量 objectId 与行为 ontologyUniqIdentifier 匹配。

# 修改范围与实现

- 新增页面私有图筛选工具：按画布连线逆向查找每个行为节点的全部上游条件，递归收集左右值及嵌套条件的对象，去重；没有对象时显示全部行为，多个对象取并集。
- 修改画布会话：暴露上游对象和行为筛选，条件或连线变化后重新校验受影响节点；明确已知不匹配的行为及其参数清空并提示重新选择，未加载到的行为不作破坏性推断。
- 修改执行行为弹窗：显示匹配选项、无匹配提示，防止通过事件或确认绕过筛选，打开旧节点时提示处理不匹配值。
- 新增相关测试，覆盖多对象、嵌套、左右值、分支、合流、未连接、空值、重新校验及取消。保留其他工作区修改；不新增依赖，不修改接口及共享类型。
