# 规则画布独立保存与回显

- 需求：依据已补充接口字段，将创建时的画布文档独立保存，并在规则详情优先恢复 switch、case 和原始节点结构。
- 范围：规则创建和详情类型、画布文档序列化与安全解析、详情回显及相关测试；新增本方案与解析工具测试，无删除文件、无新增依赖。
- 实现：创建时在 `rule.flowDocument` 写入 JSON 字符串，包含版本和规则流步骤；`judgeRules` 执行转换保持不变。详情优先校验并还原原始文档及行为参数，以只读画布呈现；无字段的历史记录继续按 judgeRules 回显，字段存在但无效时明确提示，不静默伪造画布。画布业务结构可恢复，坐标不在现有文档中，布局仍自动生成。
- 验证：先补充失败测试，覆盖 switch、if/else、多行为、异常和历史回退；运行相关测试、全量测试、覆盖率、类型规范、类型检查、临时构建、格式和 diff 检查；说明浏览器及真实接口验证缺口。
- 用户已明确要求按此前方案实施。
