# 规则变量实例单选

- 需求理解：变量实例仅允许选择一个具体实例，移除全部实例选项。
- 修改范围：变量选择弹窗和对应行为测试；保留已有画布提示修改。
- 新增文件：本方案；修改文件：ScheduleRuleVariablePicker.vue、schedule-rule-variable-picker.test.mjs；无删除文件。
- 核心实现：使用单个字符串维护选择，确认时转换为单元素 instanceIds 数组；校验实例存在于当前列表；无实例禁止确认。旧多选取首项，旧全部实例需重新选择；切换对象清空实例。
- 新增依赖：无。
