# 统一概念模型属性数据类型选项

## 需求理解

概念模型画布属性检查器的数据类型下拉选项需要与对象属性添加弹窗一致，使用完整的后端数据类型枚举。

## 修改范围

- 将概念模型画布的数据类型选项替换为对象属性添加弹窗使用的 21 个枚举值。
- 新建画布属性默认数据类型改为 `String`。
- 保留旧中文值到后端枚举的兼容映射，避免已有本地画布数据保存时产生错误。
- 更新概念模型相关测试。

## 文件变更

- 修改 `src/views/OntologyConceptualModelCreate/index.vue`。
- 修改 `tests/ontology-conceptual-model-create.test.mjs`。

不新增依赖，不修改接口、路由和受保护目录。

## 核心实现方式

复用对象属性 composable 中的完整枚举顺序，在概念模型页面维护同样的 `dataTypes` 数组；`mapCanvasDataType` 对枚举值直接返回，对旧中文值继续按原映射转换，未知值回退为 `String`。

## 验证方式

- 先增加完整枚举断言并运行定向测试确认当前实现失败。
- 完成实现后运行概念模型定向测试、格式检查、类型约定检查、类型检查、验证构建和 `git diff --check`。
