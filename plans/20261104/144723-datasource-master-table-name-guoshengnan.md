# 外键关联显示主表名称

- 需求理解：每行外键配置中，在箭头后、主表字段选择框前显示当前主表名称。
- 修改范围：数据源构建弹窗的外键关联模板及局部布局；保留已有工作区修改。
- 新增文件：本计划；修改文件：`src/views/ObjectWorkspacePanel/components/DatasourceBuildDialog.vue`；无删除文件。
- 核心实现：复用现有 `primaryTable.name` 显示主表名称，增加名称列；表名过长省略并通过悬停显示全文，调整列宽防止挤压字段选择框，保持现有窄屏布局。
- 新增依赖：无。
- 验证：纯展示调整，不改变请求和选择逻辑，不新增单元测试；执行限定文件格式检查、类型检查、临时目录构建及 diff 检查；浏览器工具不可用时明确记录视觉验收缺口。
