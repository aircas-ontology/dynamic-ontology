# 资产构建创建接口

- 需求理解：资产构建确认创建调用 POST `/ontology/meta/build_object`，按已确认的空间、对象、属性和元数据格式提交；成功刷新对象列表，失败保留数据并提示。
- 修改范围：对象接口与请求响应类型及出口、资产构建弹窗和参数转换、父页面刷新事件、HTTP Mock 与相关测试。
- 新增文件：本计划、资产构建接口类型及行为测试、必要的 Mock fixture；修改接口、类型出口、弹窗、对象工作区页面和 Mock 路由；不删除其他文件。
- 核心实现：传 spaceId、groupIds 空数组、对象信息和所选分类、继承对象、图标；属性传名称、API、类型、描述、默认值、主键、名称键、main 存储分组；表示形式按 `{"元数据":{"value":"..."}}` 写入 metadata，空值省略；Boolean 映射接口枚举 Bool。限制重复提交，处理中阻止关闭或修改，处理失败和过期响应，成功关闭并通知列表刷新。
- 新增依赖：无。
- 验证方式：先编写并运行失败测试，再实现；覆盖 API 请求格式、字段映射、空及非空元数据、成功、业务失败、网络失败、重复提交、关闭后过期响应与列表刷新；执行全量测试、覆盖率、类型规范、类型检查、build:verify、限定文件格式和 diff 检查。浏览器不可用时记录视觉及人工验收缺口。
- 用户已确认接口、方案和元数据格式。
