# 概念模型画布自动排布

- 需求理解：空间对象初次回显按关系上下左右展开，减少节点遮挡和关系线重叠；后续拖动不触发重新排布。
- 修改范围：画布响应映射、页面私有自动布局工具及关系绘制；不更改接口、保存契约或其他页面。
- 新增文件：页面私有布局工具、布局行为测试及本计划。修改响应映射和 ConceptualModelGraphCanvas.vue；必要时调整页面本地关系模型以承载初次回显的绘制信息。无删除文件。
- 核心实现：复用已有 @antv/layout 层次布局能力，根据真实节点高度布置关联对象；孤立对象以多行排列；按相对位置选择四边端口，同对象对的多条关系使用错开的中间路径，避免同线覆盖。保持用户拖动的位置，不在更新属性或选中时重新布局。
- 新增依赖：无。
- 验证方式：TDD 验证链、分支、循环、孤立对象、长属性节点、平行及反向关系、空数据和缺失端点；检查节点不重叠、关系可区分、输入不被修改及确定性；执行全量测试、覆盖率、类型检查、build:verify、限定文件格式及 diff 检查。无浏览器工具时说明运行时、主题及视觉验收缺口。
- 用户已确认方案。保留已有工作区修改。
