# 数据源构建三步流程

- 需求理解：按空间查询 schema，选择 schema 后选择数据库表，再配置字段与外键。
- 修改范围：ObjectWorkspacePanel 数据源向导、父组件空间标识传递、数据源接口及类型、创建请求、HTTP Mock 和相关测试。
- 新增文件：schema 查询 Mock fixture、行为测试；修改现有向导、接口、类型、出口、Mock 路由和相关测试；不删除文件。
- 核心实现：移除向导内连接配置，使用 spaceId/schemaName 查询表和字段并提交创建；切换 schema 清空选择；处理加载、空数据、错误、重复请求和过期响应。
- 新增依赖：无。
- 验证：先运行新增行为测试确认失败，再实现并通过；执行 npm test、覆盖率、类型规范、类型检查、build:verify、限定文件格式检查和 diff 检查。浏览器可用时仅验证本流程，否则说明缺口。
- 用户已确认实施方案。保留既有工作区修改。
