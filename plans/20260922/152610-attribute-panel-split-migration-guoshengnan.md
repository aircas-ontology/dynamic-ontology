# 属性面板拆分实现迁移方案

## 需求理解

将 `OntologyObjectAttributePanel.vue` 当前分支上的属性分类树、属性列表、表单交互和数据刷新行为同步到已拆分的页面组件、composable 与工具函数，并由主面板重新组合使用。

## 修改范围

- 分类树组件：分类节点操作、属性子节点展示、加载状态和主题样式。
- 属性表格组件：列表字段、搜索、操作按钮和加载状态。
- 分类树 composable：分类树查询、选择、增删改和树刷新。
- 属性列表 composable：属性树递归筛选、新增/编辑/删除接口和刷新回调。
- 页面工具函数与页面类型：分类树属性节点、`propertyType` 映射、分类遍历和类型导出。
- 主面板：只负责组件组合、数据源关联弹窗以及跨组件刷新协调。
- 相关静态断言测试：改为验证拆分后的文件契约。

## 核心实现方式

分类树接口返回的 `propertyInfos` 映射为属性树叶子节点；选择分类后从当前节点递归收集其下所有属性，确保可以从任意层级返回对应列表。新增、编辑、删除属性成功后重新加载分类树，分类树更新回调同步刷新右侧列表。数据源列表、字段查询及自动关联仍由主面板协调并传给现有数据源弹窗。

## 验证方式

- `npm run type-check`
- `npm run build:verify`
- 当前任务文件 `npm run format:check -- <明确文件列表>`
- 属性页、属性接口和数据源弹窗相关测试
- `git diff --check`
