# AI 助手空态与聊天左右布局

## 需求理解

没有对话时，上方继续展示上一版的助手说明和示例问题。底部聊天输入框样式保持现状。已有对话后，上方改为左右气泡：用户在右，助手在左。

## 修改范围

- 只调整 AI 助手上方展示区。
- 不改输入框结构和样式，不调用助手接口，也不编造助手回复。

## 新增、修改和删除文件

- 修改 `src/layout/components/AiAssistantDrawer.vue`
- 修改 `tests/layout-navigation.test.mjs`
- 新增本 Plan

## 核心实现方式

消息带 `user` 或 `assistant` 角色。空列表时渲染说明和示例问题。有消息时渲染对话区，用户气泡靠右，助手气泡靠左。发送只追加用户消息。

## 新增依赖及必要性

无。

## 验证方式

- 先运行左右布局断言并确认失败，再实现后确认通过。
- 对本次修改文件执行格式检查。
- 执行 `npm run build:verify`。
