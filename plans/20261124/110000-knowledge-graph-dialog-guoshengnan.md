# 知识图谱弹窗

## 需求理解

点击任务展示页的“知识图谱”按钮，打开与原型一致的右侧知识图谱侧边栏，展示当前任务主题、关联实例和事件的关系概览。

## 修改范围

- 修改 `src/views/IntelligenceTaskDisplay/index.vue`，增加弹窗开关、统计卡片、关系筛选标签和 Mock 图谱展示。
- 复用现有任务主题、目标实例和事件 Mock 数据，不接入新接口。
- 保留现有地图、目标列表、事件脉络和详情弹窗行为。

## 新增、修改和删除文件

- 新增本方案文件。
- 修改 `src/views/IntelligenceTaskDisplay/index.vue`。
- 不删除文件，不新增依赖。

## 核心实现方式

使用页面右侧侧边栏承载知识图谱面板，统计值由现有任务主题、目标和事件数据计算，使用轻量 SVG 按“主题 → 目标 → 事件”的层级绘制关系线及节点，支持关闭面板。
