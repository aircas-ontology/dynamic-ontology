# 目标关联事件与事件脉络

- 需求：点击地图目标的关联事件，在目标旁展示关联事件卡片，在页面底部展示该目标的事件脉络。
- 修改范围：任务展示页面与其地图组件；新增页面私有事件筛选工具和行为测试。保留现有未提交变更。
- 实现：按当前 Mock 的目标名称匹配事件并按时间排序；地图使用现有 Cesium 坐标投影绑定交互卡片，支持关闭和事件详情；底部时间线展示事件时间、名称、地点与状态，支持空状态和关闭。打开回放时关闭目标脉络，避免底部遮挡。
- 依赖：不新增依赖，不修改接口。
- 验证：先增加筛选、排序及空状态行为测试，再实现；执行相关测试、项目测试、覆盖率、类型检查、临时构建、格式检查及 diff 检查。地图交互和视觉效果需浏览器或人工验收。
