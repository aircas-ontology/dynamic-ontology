# 事件脉络思维导图曲线连线

## 需求理解

将任务主题展示页事件脉络思维导图中的直角连接线调整为原型图所示的弧形连接线，保留现有节点、布局和事件详情交互。

## 修改范围

- 修改 `src/views/IntelligenceTaskDisplay/index.vue` 的思维导图局部样式。
- 使用现有主题变量和 CSS 圆角边框实现根节点、阶段节点及事件分支的曲线效果。
- 不修改接口、数据结构、地图逻辑和其他页面。

## 新增、修改和删除文件

- 新增本方案文件。
- 修改 `src/views/IntelligenceTaskDisplay/index.vue`。
- 不删除文件，不新增依赖。

## 核心实现方式

在思维导图容器中增加不可交互的 SVG 连接层，根据根节点、阶段节点和事件节点的实际 DOM 坐标生成三次贝塞尔曲线。容器尺寸或事件脉络展开后重新计算路径，连接层保持 `pointer-events: none`，不影响节点点击和键盘焦点。

## 新增依赖及必要性

无。

## 验证方式

- 对修改文件执行 Prettier 格式检查。
- 运行事件脉络相关测试。
- 运行 `npm run build:verify`。
- 执行 `git diff --check` 并检查工作区变更范围。
