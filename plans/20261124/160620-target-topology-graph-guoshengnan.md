# 目标菜单图谱拓扑

## 需求理解

点击任务展示页地图目标菜单中的“图谱”按钮后，打开右侧知识图谱侧边栏，并以当前目标为中心展示其相关拓扑数据。顶部“知识图谱”入口继续展示任务主题级拓扑。

## 修改范围

- 在任务展示页增加当前图谱目标状态和目标级关系数据计算。
- 目标级关系复用现有二维关系图和 Mock 事件、目标数据，包含目标与事件、关联目标及装备的关系。
- 调整知识图谱侧边栏标题、统计和关系图数据来源。
- 调整目标菜单分支，打开目标图谱并关闭冲突面板。

## 文件

- 修改 `src/views/IntelligenceTaskDisplay/index.vue`
- 不新增依赖，不修改受保护目录。

## 核心实现方式

使用 `graphTargetId` 标识目标图谱模式。侧边栏根据该状态选择目标级或任务级关系，目标级关系由现有 `buildHiddenRelations` 生成并补充装备关系。关闭侧边栏时清除目标级状态。

## 验证方式

- 定向关系数据测试和页面相关测试。
- 对本次文件执行 Prettier 格式检查。
- 执行类型检查、构建验证、`git diff --check`。
