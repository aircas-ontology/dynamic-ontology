# 任务主题真实接口接入

## 需求理解

任务主题列表页从页面 Mock 数据切换为 `THEME_URL/task-topic` 真实接口，创建、编辑、删除也通过对应接口完成。

## 修改范围

- 任务主题列表页查询、创建、编辑、删除状态和数据映射。
- 任务主题 API 删除参数使用 `taskCode`。

## 核心实现方式

页面加载时查询接口返回数组并映射为卡片模型。创建和编辑将表单草稿转换为接口字段，编辑沿用 `taskCode`。删除逐个提交 `taskCode`，命令成功后重新查询列表。请求失败显示错误提示，不回退到 Mock 数据。

## 验证方式

- Prettier 格式检查。
- 任务主题相关测试。
- 类型检查和 `git diff --check`。

## 备注

当前开发环境无法访问在线文档地址 `172.16.18.58:37004`，接口路径和字段按仓库已确认的上一版契约接入。
