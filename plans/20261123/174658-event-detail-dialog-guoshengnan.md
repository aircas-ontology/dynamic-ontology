# 事件节点详情弹窗实施方案

## 需求理解

点击事件节点展示详情，支持关闭和按导图顺序切换上一条、下一条，首尾禁用对应操作。

## 修改范围

修改任务展示页、页面 Mock、已有业务类型及类型导出，并补充现有测试；新增本方案。不接入接口。

## 核心实现

为事件准备稳定的 Mock 详情，使用 Element Plus 弹窗展示基本信息、事件来源、描述和关联目标，通过事件 ID 管理选择和切换。

## 依赖

不新增依赖。

## 验证方式

先运行行为测试确认失败，实施后验证相关测试、类型规范、类型检查、验证构建、全量测试、覆盖率和格式。浏览器验证可用时检查弹窗和键盘交互，人工验收单独报告。
