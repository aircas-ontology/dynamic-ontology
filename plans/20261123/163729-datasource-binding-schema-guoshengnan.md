# 通过空间 Schema 判断数据源绑定

打开向导时按空间查询 Schema。成功且有结果进入对象信息，空列表进入连接选择，失败提示并允许重试。

已绑定空间进入对象信息时直接展示 Schema 选择框，选项使用空间查询结果。

初始化查询返回明确的“该对象空间未配置数据源”业务错误时，同空列表处理，进入选择或新建连接流程；其他接口失败仍显示错误并允许重试。

修改 `DatasourceBuildDialog.vue` 和 `tests/datasource-schema-flow.test.mjs`，新增本方案。复用现有查询接口和请求失效机制，无新增依赖。

先运行回归测试确认旧行为失败，再执行相关测试、全量测试、覆盖率、类型、构建和格式检查。
