# 地图目标菜单坐标绑定

## 需求理解

点击地图目标后，菜单作为地图标签跟随目标坐标，支持地图移动及二维、三维切换；菜单操作继续展示详情，并在切换、关闭或卸载时清理。

## 修改范围

修改任务展示页面及地图组件，增加页面私有菜单控制工具和行为测试；新增本计划。不修改接口及其他页面。

## 实现方式

使用现有 Mars3D DivGraphic 和独立图层承载 Vue 菜单，按目标坐标创建，响应选择和关闭，并清理地图资源。保留现有模拟数据和详情流程。

## 依赖

无新增依赖。

## 验证

先编写并运行行为测试确认失败，再实现并运行测试；执行全量测试、覆盖率、类型检查、临时目录构建验证、限定文件格式检查和差异检查。尝试针对地图交互进行浏览器冒烟；人工验收单独说明。
