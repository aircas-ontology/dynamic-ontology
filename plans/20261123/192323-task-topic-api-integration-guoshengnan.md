# 任务主题接口对接

## 需求理解

将任务主题列表的查询、创建、编辑、删除从本地 Mock 切换到 `THEME_URL` 下的四个接口。查询返回数组，编辑使用 `taskCode` 唯一标识。

## 修改范围

新增任务主题 API 函数和接口类型，更新任务主题页面的查询、创建、编辑、删除状态及映射，保留表单和卡片交互。

## 核心实现

查询进入页面时加载列表。创建和编辑提交对应请求成功后刷新列表，删除逐条按 `taskCode` 调用删除请求并刷新。失败显示服务端错误，处理中禁用重复操作。

## 依赖

无新增依赖，复用现有 request、THEME_URL 和任务表单。

## 验证方式

补充 API 与页面行为测试，执行类型规范、相关测试、格式、类型检查和验证构建。
