# 新增任务弹窗及二维地图选点

## 需求理解

按原型实现新增任务弹窗；地图使用 Cesium 二维模式，支持添加、撤销点位、坐标与区域预览；本体空间使用对象空间列表接口。

## 修改范围

新增任务弹窗和地图组件，调整任务主题入口、相关类型及测试，新增本计划；不删除文件，不新增依赖。

## 核心实现方式

复用 Mars3D/Cesium 及现有地图配置，使用二维场景并在关闭和卸载时清理实例；表单本地维护数据并校验，空间列表调用 type=0 接口。任务创建接口尚未提供，表单确认仅用于本地交互，不持久化。

## 验证方式

先添加行为测试并确认失败；实施后运行相关测试、全量测试、覆盖率、类型规范、类型检查、临时构建、格式与差异检查，并验证地图打开、选点和销毁。
