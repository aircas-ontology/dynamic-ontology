# 概念模型画布交互补全

## 需求理解
当前概念模型页仅渲染固定 HTML 卡片，未实现原型中的画布状态和建模交互。本次按原型补齐对象、属性、关系、检查器和画布工具能力。

## 修改范围
- 使用 SVG 连线与可拖拽 HTML 节点实现概念模型画布。
- 支持对象新增、选中、移动、删除和对象检查器编辑。
- 支持属性挂载到选中对象、属性检查器编辑和删除。
- 支持关系创建、端点拖动连接对象、关系检查器编辑和删除。
- 支持缩放、适应画布、清空、删除选中、保存提示。
- 不新增第三方依赖、不调整路由或后端接口。

## 文件变更
- 修改 `src/views/OntologyConceptualModelCreate/index.vue`
- 修改 `tests/ontology-conceptual-model-create.test.mjs`
- 新增本计划文件。

## 核心实现方式
使用 Vue 响应式对象、属性和关系数组维护画布草稿；使用 SVG 绘制关系线和连接端点；通过 Pointer Events 完成节点移动与关系端点连接；右侧检查器根据 `selectedElement` 切换对象、属性和关系表单。

## 新增依赖
无。

## 验证方式
执行画布专项测试、全量测试与覆盖率检查、类型检查、构建验证、任务文件格式检查，并运行差异和空白检查。
