# 全系统迁移到新版 Aircas 样式

用户已于 2026-10-10 确认实施。

## 需求理解与默认选择

统一采用新版 Aircas 暗亮主题及 Element Plus 默认外观，保留现有页面布局、业务交互和项目特有的渐变、非对称边框。迁移完成后删除旧样式体系，同步开发规范与检查脚本。默认暗色；根节点 `.dark` 存在表示暗色，移除表示亮色。不新增主题持久化或依赖，保留用户已有入口修改。

## 入口与主题切换

- 入口保持 Element Plus 官方 CSS → 官方暗色变量 → 新版 Aircas 的顺序，移除旧样式导入。
- 新增共享 `useDocumentTheme`，返回只读 `isDark` 与 `toggleTheme()`，以根节点 class 为来源，监听变化并在作用域销毁时清理。
- 顶栏状态、图标和可访问名称与实际 class 一致；全量迁移旧 theme 属性读取和选择器。
- 时间轴播放、暂停时都即时重绘。三维关系图刷新颜色、材质和纹理，保留数据、布局、镜头和自定义分类色；概念模型图刷新缓存网格，保留编辑状态。
- 不重建整个实例；替换纹理释放旧资源，卸载后停止监听及刷新。

## 颜色与组件迁移

- 按用途迁移颜色：主色、标题、焦点使用 primary；绿橙状态色使用 success、warning；文本、边框、hover、active 使用新版对应语义色。
- 面板使用背景体系，遮罩使用 overlay，避免同名不同用途的错误替换。
- 新增 `src/styles/aircas/common/_special-colors.scss`，集中维护必要的蓝紫分类色和复用效果色。蓝紫保留旧版暗亮值，透明填充、网格、边框、光晕从新版令牌派生，两套主题成对输出。
- 修复新入口滚动条未定义颜色；同步图谱字符串引用并提供渲染器可识别的实际颜色。
- 移除普通 Element Plus 旧 class、浮层 class、普通外观覆盖；保留布局、尺寸、业务类和项目自有公共组件类。
- 渐变卡片就近维护；渐变操作按钮、表头强调底边等复用例外在新版 components 中独立封装，以特殊类启用。
- 普通按钮采用现有官方 Props 和新版默认样式，移除旧 tone 和重复覆盖。
