## 1 函数编排工作流

## 开发内容

使用 logicflow 开发函数编排工作流功能。

**详细设计（图约束 / 端口与绑定 / 逻辑节点 / 保存载荷）见：**  
[`composite-workflow-design-shijian.md`](./composite-workflow-design-shijian.md)

## 功能描述

1. 可拖拽节点到画布中：拖拽左侧的逻辑节点和当前空间函数节点到画布中
2. 双击节点可弹框查看函数的详情，可调用查看函数详情接口获取数据（至少包括输入与输出参数）
3. 节点与节点之间可以连接
4. 下一个节点的输入来自上一个节点的输出，需要进行参数类型检测，如果没有上一个节点，那么输入参数可以手动输入
5. 点击保存按钮在控制台打印流程的结果数据
