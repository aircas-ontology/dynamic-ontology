# 接口名称

- 查询行为分类体系树

## 编译位置

- apis：`src/apis/actionCategoryApi.ts`
- types：`src/types/apis/getActionCategoryTreeType.ts`
- mocks：`src/mocks/getActionCategoryTreeMock/getActionCategoryTreeMock.ts`

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/行为分类体系管理/ActionCategoryController_getActionCategoryTree/doc`
- 文档标题：`GET 查询行为分类体系树`
- 文档定义的操作标识：`ActionCategoryController_getActionCategoryTree`

## 接口描述

- 根据本体空间 id 查询该空间的行为分类体系树。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/action_category/tree`

## 请求方式

- GET

## 请求参数

- `spaceId`：【query，integer / int32，必填】本体空间 id
- 请求体：无请求体。

请求示例：

```text
GET /ontology/action_category/tree?spaceId=1
```

## 输出参数

```JSON
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "id": 1,
    "name": "行为分类",
    "children": []
  }
}
```

- `code`：【integer / int32】响应码
- `message`：【string】消息描述
- `data`：【ActionCategoryVO】行为分类 VO
- `data.id`：【integer】分类节点标识，具体字段以 `ActionCategoryVO` 模型定义为准
- `data.name`：【string】分类名称，具体字段以 `ActionCategoryVO` 模型定义为准
- `data.children`：【array】子分类节点，具体字段以 `ActionCategoryVO` 模型定义为准

接口文档仅明确响应 `data` 的模型名称为 `ActionCategoryVO`，未在当前页面展开其完整字段定义；接入时应以服务端模型为准。

## 响应状态码

- `200`：请求成功
- `400`：请求参数错误
- `401`：权限不足，请重新登录
- `500`：服务器内部错误

## message

- 成功时返回接口约定的成功消息，通常为 `SUCCESS`。
- 失败时返回具体错误信息。

## apis 示例

文件：`src/apis/actionCategoryApi.ts`

```ts
import type { ActionCategoryVO, ApiResponse, GetActionCategoryTreeParams } from "@/types";
import { request } from "@/utils/request";

/**
 * 查询行为分类体系树。
 *
 * 请求方式：GET `/ontology/action_category/tree`
 *
 * @param params 查询参数。
 * @param params.spaceId 本体空间 id。
 * @returns 标准 API 响应，data 为行为分类体系树。
 */
export function getActionCategoryTreeInterface(params: GetActionCategoryTreeParams): Promise<ApiResponse<ActionCategoryVO>> {
  return request<ActionCategoryVO>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/action_category/tree",
    method: "get",
    params,
  });
}
```

并在 `src/apis/index.ts` 中导出：

```ts

```
