# 接口名称

- 创建行为分类体系树

## 编译位置

- apis：`src/apis/actionCategoryApi.ts`
- types：`src/types/apis/createActionCategoryType.ts`
- mocks：`src/mocks/createActionCategoryMock/createActionCategoryMock.ts`

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/行为分类体系管理/ActionCategoryController_createActionCategory/doc`
- 文档标题：`POST 创建行为分类体系树`
- 文档定义的操作标识：`ActionCategoryController_createActionCategory`

## 接口描述

- 创建对象空间下的行为分类体系节点。
- `parentId` 传入 `0` 时创建新的行为分类体系根节点；传入已有分类节点 id 时，在该节点下创建子节点。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/action_category`

## 请求方式

- POST

## 请求参数

- 请求参数表：无 URL query、path 或 header 业务参数。
- 所有业务参数均放在 JSON 请求体中。

## 输入参数

- 传参方式：【必须】以 **request body** 传递 JSON 对象。
- ```JSON
  {
    "spaceId": 1,
    "parentId": 0,
    "name": "飞行器行为"
  }
  ```
- `spaceId`：【integer / int32，必填】本体空间 id
- `parentId`：【integer / int32，必填】父节点 id；传入 `0` 表示当前节点为根节点并新创建行为分类体系
- `name`：【string，必填】行为分类名称

请求体中的三个字段均为必填字段，前端调用前应校验 `spaceId`、`parentId` 为整数，`name` 去除首尾空白后不能为空。

### 分类节点结构

接口模型 `CategoryNode` 包含以下字段：

- `name`：【string，必填】分类名称
- `children`：【CategoryNode[]，非必填】子节点
- `items`：【CategoryNode，非必填】分类节点

## 输出参数

```JSON
{
  "code": 200,
  "message": "SUCCESS",
  "data": null
}
```

- `code`：【integer / int32】响应码
- `message`：【string】消息描述
- `data`：【unknown】业务响应数据；接口文档未进一步定义具体响应模型

## 响应状态码

- `200`：请求成功
- `400`：请求参数错误
- `401`：权限不足，请重新登录
- `500`：服务器内部错误

## message

- 成功时返回接口约定的成功消息，通常为 `SUCCESS`。
- 失败时返回具体错误信息。

}
