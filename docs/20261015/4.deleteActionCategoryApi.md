# 接口名称

- 删除行为分类树

## 编译位置

- apis：`src/apis/actionCategoryApi.ts`
- types：`src/types/apis/deleteActionCategoryType.ts`
- mocks：`src/mocks/deleteActionCategoryMock/deleteActionCategoryMock.ts`

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/行为分类体系管理/ActionCategoryController_deleteActionCategory/doc`
- 文档标题：`DELETE 删除行为分类树`
- 文档定义的操作标识：`ActionCategoryController_deleteActionCategory`

## 接口描述

- 删除本体空间下指定的行为分类节点。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/action_category`

## 请求方式

- DELETE

## 请求参数

- 请求参数表：无 URL query、path 或 header 业务参数。
- 所有业务参数均放在 JSON 请求体中。

## 输入参数

- 传参方式：【必须】以 **request body** 传递 JSON 对象。
- ```JSON
  {
    "spaceId": 1,
    "categoryId": 2
  }
  ```
- `spaceId`：【integer / int32，必填】本体空间 id
- `categoryId`：【integer / int32，必填】行为分类 id

请求体中的两个字段均为必填字段，前端调用前应校验 `spaceId`、`categoryId` 为整数。

## 输出参数

```JSON
{
  "code": 200,
  "message": "SUCCESS",
  "data": null
}
```

- `code`：【integer / int32】响应码
- `message`：【string】消息描述
- `data`：【unknown】业务响应数据；接口文档未进一步定义具体响应模型

## 响应状态码

- `200`：请求成功
- `400`：请求参数错误
- `401`：权限不足，请重新登录
- `500`：服务器内部错误

## message

- 成功时返回接口约定的成功消息，通常为 `SUCCESS`。
- 失败时返回具体错误信息。

 *
 * @param params 行为分类删除参数。
 * @param params.spaceId 本体空间 id。
 * @param params.categoryId 行为分类 id。
 * @returns 标准 API 响应，data 由服务端接口定义。
 */
export function deleteActionCategoryInterface(params: DeleteActionCategoryParams): Promise<ApiResponse<unknown>> {
  return request<unknown>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/action_category",
    method: "delete",
    data: params,
  });
}
