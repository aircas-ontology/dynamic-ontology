# 接口名称

- 批量更新本体属性

## 接口描述

- 批量更新本体对象的属性信息。
- 对应后端 `OntologyPropertyController#batchUpdateProperties`。
- 请求体为属性更新对象数组，每个元素表示一条待更新属性。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/property/batch`

## 请求方式

- PUT

## 输入参数

- 无 Path 或 Query 参数。
- 请求体：JSON 数组，元素类型为 `OntologyPropertyUpdateParam`。

请求示例：

```json
[
  {
    "uniqueIdentifier": "property-001",
    "datasource": {
      "schemaName": "public",
      "datasourceId": "table_001",
      "datasourceColumnName": "name"
    },
    "displayName": "名称",
    "dataType": "String",
    "isTitleKey": true,
    "isPrimaryKey": false,
    "storageGroup": "main"
  }
]
```

`OntologyPropertyUpdateParam` 字段：

| 字段             | 类型                    | 必填 | 说明                                    |
| ---------------- | ----------------------- | ---- | --------------------------------------- |
| uniqueIdentifier | string                  | 是   | 属性唯一标识，后端说明为 uniqIdentifier |
| datasource       | PropertyDatasourceParam | 否   | 属性关联的数据源信息                    |
| displayName      | string                  | 是   | 属性名称                                |
| dataType         | string                  | 是   | 数据类型                                |
| isTitleKey       | boolean                 | 是   | 是否为名称键                            |
| isPrimaryKey     | boolean                 | 是   | 是否为主键                              |
| storageGroup     | string                  | 是   | 属性存储分组                            |

`PropertyDatasourceParam` 字段：

| 字段                 | 类型   | 必填 | 说明        |
| -------------------- | ------ | ---- | ----------- |
| schemaName           | string | 是   | Schema 名称 |
| datasourceId         | string | 是   | 数据源表名  |
| datasourceColumnName | string | 是   | 数据源列名  |

> `datasource` 整体为可选字段；传入该对象时，其三个子字段均为必填。

## 输出参数

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {}
}
```

| 字段    | 类型            | 说明                             |
| ------- | --------------- | -------------------------------- |
| code    | integer / int32 | 响应码                           |
| message | string          | 消息描述                         |
| data    | unknown         | 业务数据，在线文档未定义具体字段 |

## code

- `200`：请求成功。
- `400`：请求参数错误。
- `401`：权限不足，请重新登录。
- `500`：服务器内部错误。

## message

- 成功时返回：`SUCCESS`。
- 失败时返回具体错误信息。
