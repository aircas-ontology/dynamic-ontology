# 接口名称

- 删除属性元数据 schema

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 URI

- `/ontology/property/metadata_schema`

## 请求方式

- DELETE

## 输入参数

```json
{
  "ontologyIdentifier": "abcdef",
  "metadataSchemaId": 1
}
```

| 参数                 | 类型   | 必填 | 说明                                         |
| -------------------- | ------ | ---- | -------------------------------------------- |
| `ontologyIdentifier` | string | 否   | 对象 ID；应用行为可不传，由 linkMapping 推导 |
| `metadataSchemaId`   | number | 否   | 元数据 schema ID                             |

## 输出参数

在线文档声明返回 `RestResult`，包含 `code`、`message` 和 `data`；未指定 `data` 的具体内容。

## code

- 在线文档声明 HTTP `200` 响应；业务 code 和其他 HTTP 状态未明确列出。
