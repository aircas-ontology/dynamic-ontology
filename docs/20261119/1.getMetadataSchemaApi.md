# 接口名称

- 查询属性元数据 schema 树

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 URI

- `/ontology/property/metadata_schema/tree`

## 请求方式

- GET

## 输入参数

| 参数                       | 类型   | 必填 | 说明                  |
| -------------------------- | ------ | ---- | --------------------- |
| `ontologyUniqueIdentifier` | string | 是   | 对象 uniqueIdentifier |

## 输出参数

在线接口将 `data` 声明为 `PropertyMetadataSchemaVO` 对象，`children` 递归引用同一模型。模型未标记必填字段；示例展示字段结构，实际返回仍需通过登录后的响应核实。

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "schemaId": 1,
    "name": "等级",
    "valueType": "ENUM",
    "value": "一级,二级",
    "children": []
  }
}
```

- `data.schemaId`：【number】元数据 schema ID
- `data.name`：【string】名称
- `data.valueType`：【`INPUT` | `ENUM` | `RANGE`】取值类型
- `data.value`：【string】取值内容；枚举为逗号分隔候选项，范围形如 `0,100`，输入值可空
- `data.children`：【object[]】子节点，节点结构与 `data` 相同

## code

- 在线文档声明 HTTP `200` 响应；业务 code 和其他 HTTP 状态未明确列出。
