# 接口名称

- 创建属性元数据 schema

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 URI

- `/ontology/property/metadata_schema`

## 请求方式

- POST

## 输入参数

```json
{
  "ontologyIdentifier": "abcdef",
  "parentId": 0,
  "name": "信息等级",
  "valueType": "ENUM",
  "value": "高,中,低",
  "children": [{ "name": "保密级别", "valueType": "ENUM", "value": "一级,二级" }]
}
```

| 参数                 | 类型     | 必填 | 说明                                                              |
| -------------------- | -------- | ---- | ----------------------------------------------------------------- |
| `ontologyIdentifier` | string   | 否   | 对象 ID；应用行为可不传，由 linkMapping 推导                      |
| `parentId`           | number   | 是   | 父节点 ID，`0` 表示根节点                                         |
| `name`               | string   | 是   | 名称                                                              |
| `valueType`          | string   | 否   | `INPUT`、`ENUM` 或 `RANGE`，默认 `INPUT`                          |
| `value`              | string   | 否   | 枚举候选项以逗号分隔，范围形如 `0,100`，输入值可空                |
| `enumValues`         | string[] | 否   | 已废弃，仅兼容旧导出文件                                          |
| `children`           | object[] | 否   | 子节点，节点包含 `name`、`valueType`、`value` 和可选的 `children` |

## 输出参数

在线文档声明返回 `RestResult`，包含 `code`、`message` 和 `data`；未指定 `data` 的具体内容。

## code

- 在线文档声明 HTTP `200` 响应；业务 code 和其他 HTTP 状态未明确列出。
