# 任务主题创建接口说明

## 接口名称

- 创建任务主题
- OpenAPI 操作：`TaskTopicController_create`

## 接口 domain

- `DOMAIN_CONFIG.THEME_URL`

## 接口 URI

- `/task-topic`

## 请求方式

- `POST`

## 请求体

请求体使用 JSON。

```json
{
  "creator": "admin",
  "endTime": "2024-01-01T00:00:00Z",
  "startTime": "2024-01-01T00:00:00Z",
  "status": 0,
  "taskName": "区域巡查",
  "taskRegion": "华东",
  "regionPoint": "121.420244,24.389790;121.520244,24.489790;121.620244,24.589790",
  "taskType": "巡查",
  "description": "",
  "ontologySpace": "space-a,space-b"
}
```

| 字段            | 类型               | 必填 | 说明                               |
| --------------- | ------------------ | ---- | ---------------------------------- |
| `creator`       | string             | 否   | 创建人                             |
| `endTime`       | string / date-time | 否   | 任务结束时间                       |
| `startTime`     | string / date-time | 否   | 任务开始时间                       |
| `status`        | string             | 否   | 任务状态                           |
| `taskCode`      | string             | 否   | 任务编号                           |
| `taskName`      | string             | 否   | 任务名称                           |
| `taskRegion`    | string             | 否   | 任务区域                           |
| `regionPoint`   | string             | 否   | 区域点位，格式为 `lon,lat;lon,lat` |
| `taskType`      | string             | 否   | 任务类型                           |
| `description`   | string             | 否   | 任务描述                           |
| `ontologySpace` | string             | 否   | 关联本体空间，多个值使用逗号分隔   |

## 响应结构

在线文档返回标准业务响应，具体 `data` 内容以服务端声明为准。

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {}
}
```

## 前端调用地址

```ts
DOMAIN_CONFIG.THEME_URL + "/task-topic";
```
