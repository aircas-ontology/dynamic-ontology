# 任务主题查询接口说明

## 接口名称

- 查询任务主题列表
- OpenAPI 操作：`TaskTopicController_list`

## 接口 domain

- `DOMAIN_CONFIG.THEME_URL`

## 接口 URI

- `/task-topic`

## 请求方式

- `GET`

## 请求参数

请求参数以 query 方式传递。分页字段及筛选字段以在线文档实际声明为准。

| 参数       | 类型    | 必填 | 说明     |
| ---------- | ------- | ---- | -------- |
| `pageNum`  | integer | 否   | 页码     |
| `pageSize` | integer | 否   | 每页数量 |

## 响应结构

`data` 直接为任务主题数组，数组字段对应 `TaskTopicVO`。

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": [
    {
      "id": "1",
      "taskName": "区域巡查",
      "taskType": "巡查",
      "taskRegion": "华东",
      "regionPoint": "121.420244,24.389790;121.520244,24.489790;121.620244,24.589790",
      "startTime": "2024-01-01T00:00:00Z",
      "endTime": "2024-01-01T00:00:00Z",
      "description": "",
      "ontologySpace": "space-a,space-b",
      "status": "进行中",
      "creator": "admin",
      "createTime": "2024-01-01T00:00:00Z",
      "targetCount": 0,
      "seaCount": 0,
      "airCount": 0,
      "landCount": 0,
      "eventCount": 0
    }
  ]
}
```

## `TaskTopicVO` 字段

| 字段            | 类型               | 说明                               |
| --------------- | ------------------ | ---------------------------------- |
| `taskCode`      | string             | 任务编号                           |
| `taskName`      | string             | 任务名称                           |
| `taskType`      | string             | 任务类型                           |
| `taskRegion`    | string             | 任务区域                           |
| `regionPoint`   | string             | 区域点位，格式为 `lon,lat;lon,lat` |
| `startTime`     | string / date-time | 任务开始时间                       |
| `endTime`       | string / date-time | 任务结束时间                       |
| `description`   | string             | 任务描述                           |
| `ontologySpace` | string             | 关联本体空间，多个值使用逗号分隔   |
| `status`        | string             | 任务状态                           |
| `creator`       | string             | 创建人                             |
| `createTime`    | string / date-time | 创建时间                           |
| `targetCount`   | integer / int32    | 目标数量                           |
| `seaCount`      | integer / int32    | 海上目标数量                       |
| `airCount`      | integer / int32    | 空中目标数量                       |
| `landCount`     | integer / int32    | 陆上目标数量                       |
| `eventCount`    | integer / int32    | 事件数量                           |

## 前端调用地址

```ts
DOMAIN_CONFIG.THEME_URL + "/task-topic";
```
