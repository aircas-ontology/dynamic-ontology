# 任务主题删除接口说明

## 接口名称

- 删除任务主题
- OpenAPI 操作：`TaskTopicController_delete`

## 接口 domain

- `DOMAIN_CONFIG.THEME_URL`

## 接口 URI

- `/task-topic/{id}`

## 请求方式

- `DELETE`

## 请求参数

删除标识按在线文档声明的位置传递。常见契约为 query 参数，接入时以文档中的参数名和位置为准。

| 参数 | 类型    | 必填 | 说明                       |
| ---- | ------- | ---- | -------------------------- |
| `id` | integer | 是   | 任务主题主键，拼接到路径中 |

## 响应结构

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {}
}
```

删除成功后刷新任务主题列表，失败时保留列表并展示服务端 `message`。

## 前端调用地址

```ts
`${DOMAIN_CONFIG.THEME_URL}/task-topic/${id}`;
```
