# 任务主题编辑接口说明

## 接口名称

- 编辑任务主题
- OpenAPI 操作：`TaskTopicController_update`

## 接口 domain

- `DOMAIN_CONFIG.THEME_URL`

## 接口 URI

- `/task-topic`

## 请求方式

- `PUT`

## 请求体

请求体使用 JSON，字段与创建接口一致，使用 `id` 作为任务主题唯一标识。地图区域通过 `regionPoint` 传递，格式为 `lon,lat;lon,lat`。

```json
{
  "id": 1,
  "creator": "admin",
  "endTime": "2024-01-01T00:00:00Z",
  "startTime": "2024-01-01T00:00:00Z",
  "status": "进行中",
  "taskName": "区域巡查",
  "taskRegion": "华东",
  "taskType": "巡查",
  "description": "",
  "ontologySpace": "space-a,space-b"
}
```

## 响应结构

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {}
}
```

编辑成功后刷新任务主题列表，失败时展示服务端 `message`。

## 前端调用地址

```ts
DOMAIN_CONFIG.THEME_URL + "/task-topic";
```
