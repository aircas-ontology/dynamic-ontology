# 接口名称

- 删除限流配置模板

## 编译位置

- apis：`src/apis/functionRateLimitTemplateApi.ts`
- types：`src/types/apis/deleteFunctionRateLimitTemplateType.ts`
- mocks：`src/mocks/deleteFunctionRateLimitTemplateMock/deleteFunctionRateLimitTemplateMock.ts`

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/限流配置模板/FunctionRateLimitTemplateController_delete/doc`
- OpenAPI 定义：`http://172.16.18.58:37002/ontology/v3/api-docs`
- 文档标题：`DELETE 删除限流配置模板`
- 操作标识：`FunctionRateLimitTemplateController_delete`
- 核对日期：2026-10-26

## 接口描述

- 根据模板 ID 删除指定限流配置模板。
- 操作成功后重新查询全部模板列表，更新界面；失败保留原记录和启停状态并提示错误。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/function/rate_limit_template`
- OpenAPI server 包含 `/ontology`，paths 不含此前缀。此 uri 用于拼接不含 `/ontology` 的服务域名，避免重复添加。

## 请求方式

- DELETE
- 无请求体。

## 请求参数

| 参数 | 位置  | 类型            | 必填 | 说明    |
| ---- | ----- | --------------- | ---- | ------- |
| id   | query | integer / int64 | 是   | 模板 ID |

- 无 path 或 header 业务参数；不是 JSON body，也不是路径参数。
- 文档未声明 ID 数值范围；前端 number 应确保 ID 在安全整数范围内。

## 输入参数

- 以 URL query 传递，在请求工具中使用 params。
- 请求示例：`DELETE /ontology/function/rate_limit_template?id=1`，其中 1 为演示 ID。

## 输出参数

响应模型：`RestResultVoid`。以下为演示结构，code、message、data 示例值不是 OpenAPI 声明的固定值：

```json
{ "code": 200, "message": "SUCCESS", "data": null }
```

- `code`：【integer / int32】业务响应码，成功取值需遵循服务端实际约定；当前页面沿用 200。
- `message`：【string】消息描述。
- `data`：【unknown】文档仅定义空 schema，未声明具体类型，不用于更新列表。
- 响应未声明 required 字段列表；未声明 success 字段。

## 响应状态码

- `200`：`OK`，文档唯一声明的 HTTP 响应状态。
- 未声明其他状态码及错误响应模型，不补造为既定契约。

## message

- 文档未约定固定消息，SUCCESS 仅为示例；失败展示实际错误信息。
