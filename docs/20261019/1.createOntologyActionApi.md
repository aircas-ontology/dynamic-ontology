# 接口名称

- 新增行为

## 编译位置

- apis：`src/apis/ontologyActionApi.ts`
- types：`src/types/apis/createOntologyActionType.ts`
- mocks：`src/mocks/createOntologyActionMock/createOntologyActionMock.ts`

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/对象行为/OntologyActionController_createAction/doc`
- 文档标题：`POST 新增行为`
- 文档定义的操作标识：`OntologyActionController_createAction`

## 接口描述

- 在指定对象下新增行为。
- 行为可配置关联关系映射和行为参数映射，用于描述行为调用所需的对象关系及属性参数。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/action`

## 请求方式

- POST

## 请求参数

- 请求参数表：无 URL query、path 或 header 业务参数。
- 所有业务参数均放在 JSON 请求体中。

## 输入参数

- 传参方式：【必须】以 **request body** 传递 JSON 对象。
- ```JSON
  {
    "ontologyIdentifier": "abcdef",
    "icon": "http://192.168.9.11/aa.jpeg",
    "actionApi": "satellite",
    "functionApi": "satellite",
    "description": "这是一个行为",
    "displayName": "调用函数",
    "linkMapping": {
      "ontologyLinkUniqIdentifier": "link-001",
      "ontologyLinkFunctionParamExpression": "data.user[0].name"
    },
    "mappingIns": [
      {
        "functionParamId": 1,
        "functionParamExpression": "data.user[0].name",
        "propertyUniqueIdentifier": "property-001",
        "ontologyUniqueIdentifier": "abcdef"
      }
    ]
  }
  ```
- `ontologyIdentifier`：【string，必填】对象 id，不能为空
- `icon`：【string，必填】图片 URL
- `actionApi`：【string，必填】行为 API 名称，不能为空
- `functionApi`：【string，非必填】对象下函数 API
- `description`：【string，非必填】行为描述
- `displayName`：【string，必填】行为显示名称，不能为空
- `linkMapping`：【ActionLinkMappingParam，非必填】行为关系映射
- `mappingIns`：【ActionParamMappingCreateParam[]，非必填】行为参数列表

### 行为关系映射结构

接口模型 `ActionLinkMappingParam` 包含以下字段：

- `ontologyLinkUniqIdentifier`：【string，非必填】行为关联的关系 id
- `ontologyLinkFunctionParamExpression`：【string，非必填】行为关联的函数参数表达式

### 行为参数映射结构

接口模型 `ActionParamMappingCreateParam` 包含以下字段：

- `functionParamId`：【integer / int64，非必填】参数对应的函数参数 ID
- `functionParamExpression`：【string，非必填】行为对应的函数参数表达式
- `propertyUniqueIdentifier`：【string，非必填】参数对应的对象属性 ID
- `ontologyUniqueIdentifier`：【string，非必填】参数对应的对象 ID

请求体中的 `ontologyIdentifier`、`icon`、`actionApi`、`displayName` 为必填字段，前端调用前应校验其为空值和首尾空白。

## 输出参数

```JSON
{
  "code": 200,
  "message": "SUCCESS",
  "data": null
}
```

- `code`：【integer / int32】响应码
- `message`：【string】消息描述
- `data`：【unknown】业务响应数据；接口文档未进一步定义具体响应模型

## 响应状态码

- `200`：请求成功
- `400`：请求参数错误
- `401`：权限不足，请重新登录
- `500`：服务器内部错误

## message

- 成功时返回接口约定的成功消息，通常为 `SUCCESS`。
- 失败时返回具体错误信息。

## apis 示例

文件：`src/apis/ontologyActionApi.ts`

```ts
import type { ApiResponse, CreateOntologyActionParams } from "@/types";
import { request } from "@/utils/request";

/**
 * 创建对象行为。
 *
 * 请求方式：POST `/ontology/action`
 *
 * @param params 对象行为创建参数。
 * @returns 标准 API 响应，data 由服务端接口定义。
 */
export function createOntologyActionInterface(params: CreateOntologyActionParams): Promise<ApiResponse<unknown>> {
  return request<unknown>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/action",
    method: "post",
    data: params,
  });
}
```

并在 `src/apis/index.ts` 中导出：

```ts
import { createOntologyActionInterface } from "./ontologyActionApi";

export { createOntologyActionInterface };
```
