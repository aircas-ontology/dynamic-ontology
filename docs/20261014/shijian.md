## 1 脚本函数算子测试功能

## 功能描述

脚本函数的测试界面与基础函数的测试界面不太一样，要使用单独的组件；
点击脚本函数卡片或列表的测试按钮弹出脚本函数的测试弹框界面；
脚本函数测试弹框界面为输入参数表单和执行结果区域
输入参数名需要调用 函数详情接口 获取，然后输入参数值，注意把参数类型也展示出来
请求完成后把请求返回的全部数据展示到执行结果区域即可

## 测试接口调用

该功能为调用/ontology/function/test 接口（接口文档testFunApt-shijian.md） 测试函数能力。

脚本函数测试请求参数示例
{
"functionApi": "smoke.hello.py",
"version": "1.0.0",
"parameters": [ { "paramName": "name", "paramValue": "foundry" } ]
}
