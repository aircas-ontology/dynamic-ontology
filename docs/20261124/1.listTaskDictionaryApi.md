# 任务主题字典查询接口说明

## 接口名称

- 查询字典列表
- OpenAPI 操作：`DictController_list`
- 文档地址：[工具字典接口文档](http://172.16.18.58:37004/topic/doc.html#/topic/%E5%AD%97%E5%85%B8/DictController_list/doc)

## 接口 domain

- `DOMAIN_CONFIG.THEME_URL`

## 接口 URI

- `/dict`

## 请求方式

- `GET`

## 请求参数

| 参数        | 类型   | 必填 | 说明       |
| ----------- | ------ | ---- | ---------- |
| `groupCode` | string | 是   | 字典组编码 |

## 请求示例

```ts
getTaskTopicDictionaryInterface("task_type");
getTaskTopicDictionaryInterface("task_region");
```

## 响应结构

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": [
    {
      "id": "1",
      "dictName": "军事作战"
    }
  ]
}
```

## 任务页面对接

- 新建或编辑任务弹窗打开时查询 `task_type` 和 `task_region`。
- 任务类型下拉框使用 `groupCode=task_type` 返回数据，选项值使用 `id`。
- 任务区域下拉框使用 `groupCode=task_region` 返回数据。
- 任务创建和编辑请求分别使用 `task_type`、`task_region` 字段。
- 字典查询失败时清空对应选项并显示错误信息。

## 前端调用地址

```ts
DOMAIN_CONFIG.THEME_URL + "/dict";
```
