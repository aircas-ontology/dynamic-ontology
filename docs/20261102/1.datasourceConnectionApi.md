# 数据源连接配置接口说明

## 接口概述

- 接口服务：本体服务
- 接口分组：数据源连接配置
- 基础路径：`/ontology`
- OpenAPI 控制器：`DatasourceConnectionController`
- 文档来源：数据源连接配置接口文档（`DatasourceConnectionController_list`）

本文档覆盖数据源连接配置管理及“数据源构建对象”向导所需的接口。

## 1. 分页查询数据源列表

- 接口地址：`GET /ontology/datasource/connection/list`
- 方法：`DatasourceConnectionController_list`
- 说明：分页查询数据源列表，`keyword` 按名称或数据库类型模糊匹配；`status` 不传时查询全部；响应不返回密码。

### 请求参数

| 参数       | 位置  | 类型            | 必填 | 默认值 | 说明                                       |
| ---------- | ----- | --------------- | ---- | ------ | ------------------------------------------ |
| `keyword`  | query | string          | 否   | `""`   | 按数据源名称或数据库类型模糊匹配           |
| `status`   | query | integer / int32 | 否   | -      | 状态过滤：`1` 启用，`0` 禁用，不传查询全部 |
| `pageNum`  | query | integer / int32 | 否   | `1`    | 页码，从 1 开始                            |
| `pageSize` | query | integer / int32 | 否   | `20`   | 每页条数                                   |

请求示例：

```text
GET /ontology/datasource/connection/list?keyword=postgres&pageNum=1&pageSize=20
```

### 响应示例

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "size": 20,
    "current": 1,
    "records": [
      {
        "id": 1,
        "name": "生产订单库",
        "dbType": "POSTGRESQL",
        "driverClass": "org.postgresql.Driver",
        "jdbcUrl": "jdbc:postgresql://172.16.18.58:35432/entity_datasource",
        "host": "172.16.18.58",
        "port": 35432,
        "dbName": "entity_datasource",
        "schemaName": "public",
        "username": "postgres",
        "description": "订单中心主库，只读账号",
        "status": 1,
        "createTime": "2026-11-02T10:43:02+08:00",
        "updateTime": "2026-11-02T10:43:02+08:00"
      }
    ],
    "total": 1,
    "pages": 1
  }
}
```

`data` 分页字段：`records` 为数据源记录，`total` 为总数，`size` 为页大小，`current` 为当前页码，`pages` 为总页数且已标记废弃，前端不应依赖。

## 2. 查询单个数据源

- 接口地址：`GET /ontology/datasource/connection/detail`
- 方法：`DatasourceConnectionController_detail`
- 说明：查询单个数据源用于编辑表单回显，不返回密码。

| 参数 | 位置  | 类型            | 必填 | 说明      |
| ---- | ----- | --------------- | ---- | --------- |
| `id` | query | integer / int32 | 是   | 数据源 id |

请求示例：

```text
GET /ontology/datasource/connection/detail?id=1
```

响应 `data` 类型为 `DatasourceConnectionItemVO`，字段见“数据模型”。

## 3. 新增数据源

- 接口地址：`POST /ontology/datasource/connection`
- 方法：`DatasourceConnectionController_create`
- 说明：新增数据源。`id`、创建时间和更新时间由后台生成；`password` 必填；`status` 不传时按启用保存。

### 请求体

```json
{
  "name": "生产订单库",
  "dbType": "POSTGRESQL",
  "driverClass": "org.postgresql.Driver",
  "jdbcUrl": "jdbc:postgresql://172.16.18.58:35432/entity_datasource",
  "host": "172.16.18.58",
  "port": 35432,
  "dbName": "entity_datasource",
  "schemaName": "public",
  "username": "postgres",
  "password": "123456",
  "description": "订单中心主库，只读账号",
  "status": 1
}
```

请求体必填字段：`name`、`dbType`、`jdbcUrl`、`username`；新增业务规则还要求 `password` 必填。

## 4. 修改数据源

- 接口地址：`PUT /ontology/datasource/connection?id={id}`
- 方法：`DatasourceConnectionController_update`
- 说明：`id` 通过 query 参数传递。除密码外，请求体字段按入参覆盖；传空字符串会清空对应列；`password` 留空表示沿用数据库中的原密码。

请求示例：

```text
PUT /ontology/datasource/connection?id=1
Content-Type: application/json
```

请求体格式与新增数据源相同。响应 `data` 类型为 `DatasourceConnectionItemVO`，不包含密码。

## 5. 删除数据源

- 接口地址：`DELETE /ontology/datasource/connection?id={id}`
- 方法：`DatasourceConnectionController_delete`
- 说明：物理删除数据源。仅需要临时下架时，应调用修改接口将 `status` 设为 `0`。

| 参数 | 位置  | 类型            | 必填 | 说明      |
| ---- | ----- | --------------- | ---- | --------- |
| `id` | query | integer / int32 | 是   | 数据源 id |

响应 `data` 为空，响应模型为 `RestResultVoid`。

## 6. 测试数据源连接

- 接口地址：`POST /ontology/datasource/connection/test`
- 方法：`DatasourceConnectionController_test`
- 说明：只建立一次连接并读取数据库名称和版本，不执行 SQL、不落库。传入 `id` 时，以数据库中该条配置为基础，用表单中非空字段覆盖；编辑场景可以不传密码。

| 参数 | 位置  | 类型            | 必填 | 说明              |
| ---- | ----- | --------------- | ---- | ----------------- |
| `id` | query | integer / int32 | 否   | 已保存的数据源 id |

请求体使用 `DatasourceConnectionParam`。成功响应的 `data` 类型为 string，内容为数据库名称与版本信息。

## 7. 列出数据源表

- 接口地址：`GET /ontology/datasource/connection/table/list`
- 方法：`DatasourceConnectionController_listTables`
- 说明：列出外部数据源中的表名、表注释和字段数，用于“数据源构建对象”向导的选表步骤。该接口与查询数据湖空间内表的 `/datasource/table` 不同。

| 参数           | 位置  | 类型            | 必填 | 说明      |
| -------------- | ----- | --------------- | ---- | --------- |
| `datasourceId` | query | integer / int32 | 是   | 数据源 id |

响应 `data` 类型为 `DatasourceTableSummaryVO[]`：

| 字段           | 类型            | 说明                              |
| -------------- | --------------- | --------------------------------- |
| `tableName`    | string          | 表名                              |
| `tableComment` | string          | 表注释，驱动未开启 remarks 时为空 |
| `columnCount`  | integer / int32 | 字段数                            |

## 8. 查询多张表的字段和外键候选

- 接口地址：`GET /ontology/datasource/connection/table/columns`
- 方法：`DatasourceConnectionController_listTableColumns`
- 说明：列出指定数据源中多张表的列、主键和主子表外键候选。外键只返回本次传入表集合内部的关系，每张子表最多一条；`origin=HEURISTIC` 表示按同名列推断，需要用户确认。

| 参数           | 位置  | 类型            | 必填 | 说明                       |
| -------------- | ----- | --------------- | ---- | -------------------------- |
| `datasourceId` | query | integer / int32 | 是   | 数据源 id                  |
| `tableNames`   | query | string[]        | 是   | 表名，逗号分隔，区分大小写 |

请求示例：

```text
GET /ontology/datasource/connection/table/columns?datasourceId=1&tableNames=ship,ship_weapon
```

响应 `data` 类型为 `DatasourceTableDetailVO[]`：

| 字段                | 类型           | 说明                                         |
| ------------------- | -------------- | -------------------------------------------- |
| `tableName`         | string         | 表名                                         |
| `tableComment`      | string         | 表注释                                       |
| `primaryKeyColumns` | string[]       | 主键列名，按数据库声明顺序，无主键时为空数组 |
| `columns`           | `Column[]`     | 列清单，按 `ORDINAL_POSITION` 升序           |
| `foreignKeys`       | `ForeignKey[]` | 本次选中表集合内部指向主表的外键候选         |

`Column` 字段：

| 字段               | 类型    | 说明                                        |
| ------------------ | ------- | ------------------------------------------- |
| `columnName`       | string  | 列名                                        |
| `nativeType`       | string  | 数据库原生类型，如 `BIGINT`、`varchar(255)` |
| `description`      | string  | 列注释                                      |
| `isPrimaryKey`     | boolean | 是否为主键列                                |
| `ontologyDataType` | string  | 归一化后的本体属性类型                      |

`ForeignKey` 字段：

| 字段           | 类型   | 说明                                                            |
| -------------- | ------ | --------------------------------------------------------------- |
| `masterTable`  | string | 主表名                                                          |
| `masterColumn` | string | 主表被引用列                                                    |
| `childTable`   | string | 子表名                                                          |
| `childColumn`  | string | 子表外键列                                                      |
| `origin`       | string | `DECLARED`：数据库声明外键；`HEURISTIC`：同名列推断，需用户确认 |

## 数据模型

### DatasourceConnectionParam

| 字段          | 类型            | 必填     | 说明                                                                                          |
| ------------- | --------------- | -------- | --------------------------------------------------------------------------------------------- |
| `name`        | string          | 是       | 数据源名称，允许重复，最长 128                                                                |
| `dbType`      | string          | 是       | 数据库类型，如 `POSTGRESQL`、`MYSQL`、`MARIADB`、`ORACLE`、`SQLSERVER`，不区分大小写，最长 32 |
| `driverClass` | string          | 否       | JDBC 驱动类全限定名，留空时依赖驱动 SPI，最长 255                                             |
| `jdbcUrl`     | string          | 是       | 完整 JDBC URL，最长 1024                                                                      |
| `host`        | string          | 否       | 主机地址，便于列表展示，最长 255                                                              |
| `port`        | integer / int32 | 否       | 端口号                                                                                        |
| `dbName`      | string          | 否       | 数据库名，最长 128                                                                            |
| `schemaName`  | string          | 否       | Schema 名，最长 128；为空时使用厂商默认值                                                     |
| `username`    | string          | 是       | 连接用户名，最长 128                                                                          |
| `password`    | string          | 业务相关 | 新增时必填；修改时留空表示不修改原密码，最长 255                                              |
| `description` | string          | 否       | 数据源描述，最长 512                                                                          |
| `status`      | integer / int32 | 否       | `1` 启用，`0` 禁用；不传默认 `1`                                                              |

### DatasourceConnectionItemVO

管理接口返回的数据源配置，不包含密码。

| 字段          | 类型               | 说明               |
| ------------- | ------------------ | ------------------ |
| `id`          | integer / int32    | 数据源主键         |
| `name`        | string             | 数据源名称         |
| `dbType`      | string             | 数据库类型         |
| `driverClass` | string             | JDBC 驱动类        |
| `jdbcUrl`     | string             | JDBC URL           |
| `host`        | string             | 主机地址           |
| `port`        | integer / int32    | 端口号             |
| `dbName`      | string             | 数据库名           |
| `schemaName`  | string             | Schema 名          |
| `username`    | string             | 连接用户名         |
| `description` | string             | 数据源描述         |
| `status`      | integer / int32    | `1` 启用，`0` 禁用 |
| `createTime`  | string / date-time | 创建时间           |
| `updateTime`  | string / date-time | 更新时间           |

## 通用响应

除分页列表外，接口均使用 `code`、`message`、`data` 三个顶层字段：

| 字段      | 类型                    | 说明                       |
| --------- | ----------------------- | -------------------------- |
| `code`    | integer / int32         | 响应码，成功通常为 `200`   |
| `message` | string                  | 响应消息                   |
| `data`    | object / array / string | 具体响应数据；删除接口为空 |

常见错误状态：`400` 请求参数错误，`401` 未授权，`403` 无权限，`404` 资源不存在，`500` 服务端错误。具体错误信息以 `message` 为准。
