# 接口名称

- 删除函数算子代码模板

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/函数算子代码模板/FunctionOperatorTemplateController_delete/doc`
- 文档标题：`DELETE 删除函数算子代码模板`
- 文档定义的操作标识：`FunctionOperatorTemplateController_delete`

## 接口描述

- 根据 query 参数中的模板 ID 删除指定函数算子代码模板。
- 请求不包含 JSON body。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/function/operator_template`

## 请求方式

- DELETE

## 请求参数

- `id`：【integer / int64，必填，query】模板 ID。

请求示例：

```text
DELETE /function/operator_template?id=1
```

## 输出参数

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": null
}
```

- `code`：【integer / int32】响应码
- `message`：【string】消息描述
- `data`：【unknown】删除接口无业务响应数据
