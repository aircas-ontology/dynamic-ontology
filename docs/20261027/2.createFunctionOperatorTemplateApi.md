# 接口名称

- 创建函数算子代码模板

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/函数算子代码模板/FunctionOperatorTemplateController_create/doc`
- 文档标题：`POST 创建函数算子代码模板（ID、创建/更新时间由后台生成，请求体只传名称/语言/说明/代码）`
- 文档定义的操作标识：`FunctionOperatorTemplateController_create`

## 接口描述

- 创建函数算子代码模板。
- `id`、`createTime`、`updateTime` 由后台生成，请求体只传名称、语言、说明和代码。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/function/operator_template`

## 请求方式

- POST

## 输入参数

```json
{
  "name": "Groovy 文本转整数模板",
  "language": "GROOVY",
  "description": "将文本转换为整数",
  "code": "return value as Integer"
}
```

- `name`：【string，必填，最长 50】模板名称，全局唯一
- `language`：【string，必填】脚本语言：`GROOVY`、`JAVA`、`PYTHON`、`TYPESCRIPT`
- `description`：【string，非必填，最长 500】模板说明
- `code`：【string，必填】模板代码内容，不能为空

## 输出参数

- `data`：【FunctionOperatorTemplate】创建后的模板，字段包括 `id`、`name`、`language`、`description`、`code`、`createTime`、`updateTime`。
