# 接口名称

- 修改函数算子代码模板

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/函数算子代码模板/FunctionOperatorTemplateController_update/doc`
- 文档标题：`PUT 更新函数算子代码模板（ID 走 query 参数，更新时间由后台生成）`
- 文档定义的操作标识：`FunctionOperatorTemplateController_update`

## 接口描述

- 根据 query 参数中的模板 ID 修改函数算子代码模板。
- 更新时间由后台生成，模板 ID 不放入 JSON 请求体。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/function/operator_template`

## 请求方式

- PUT

## 请求参数

- `id`：【integer / int64，必填，query】模板 ID。

## 输入参数

```json
{
  "name": "Groovy 文本转整数模板（更新）",
  "language": "GROOVY",
  "description": "更新后的模板说明",
  "code": "return Integer.valueOf(value)"
}
```

- `name`：【string，必填，最长 50】模板名称，全局唯一
- `language`：【string，必填】脚本语言：`GROOVY`、`JAVA`、`PYTHON`、`TYPESCRIPT`
- `description`：【string，非必填，最长 500】模板说明
- `code`：【string，必填】模板代码内容，不能为空

## 输出参数

- `data`：【FunctionOperatorTemplate】更新后的模板，字段包括 `id`、`name`、`language`、`description`、`code`、`createTime`、`updateTime`。
