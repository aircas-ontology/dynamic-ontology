# 接口名称

- 查询函数算子代码模板列表

## 接口来源

- Knife4j 文档：`http://172.16.18.58:37002/ontology/doc.html#/ontology/函数算子代码模板/FunctionOperatorTemplateController_listTemplates/doc`
- 文档标题：`GET 查询模板列表（name 不传查全部，传了按名称模糊匹配；language 不传查全部语言）`
- 文档定义的操作标识：`FunctionOperatorTemplateController_listTemplates`

## 接口描述

- 查询函数算子代码模板列表。
- `name` 不传时查询全部模板，传入时按名称模糊匹配。
- `language` 不传时查询全部语言，否则按脚本语言筛选。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/function/operator_template/list`

## 请求方式

- GET

## 请求参数

| 参数       | 位置  | 类型   | 必填 | 说明                                               |
| ---------- | ----- | ------ | ---- | -------------------------------------------------- |
| `name`     | query | string | 否   | 模板名称，按名称模糊匹配                           |
| `language` | query | string | 否   | 脚本语言：`GROOVY`、`JAVA`、`PYTHON`、`TYPESCRIPT` |

## 输出参数

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": [
    {
      "id": 1,
      "name": "Groovy 文本转整数模板",
      "language": "GROOVY",
      "description": "模板说明",
      "code": "return value as Integer",
      "createTime": "2026-10-27T10:00:00+08:00",
      "updateTime": "2026-10-27T10:00:00+08:00"
    }
  ]
}
```

- `code`：【integer / int32】响应码
- `message`：【string】消息描述
- `data`：【FunctionOperatorTemplate[]】模板列表
- `data[].id`：【integer / int64】模板 ID
- `data[].name`：【string】模板名称，全局唯一
- `data[].language`：【string】脚本语言
- `data[].description`：【string】模板说明
- `data[].code`：【string】模板代码内容
- `data[].createTime`：【string / date-time】创建时间
- `data[].updateTime`：【string / date-time】更新时间
