# 查询单对象单个实体所有关联关系

## 来源与目标

- 来源：[后端接口文档](http://172.16.18.58:37002/ontology/doc.html#/ontology/%E5%AE%9E%E4%BD%93%E7%AE%A1%E7%90%86/OntologyEntityController_getEntityLinksByPrimaryKey/doc)，读取时间 2026-11-17。
- 校对依据：同服务 `/ontology/v3/api-docs` 中的 Operation ID `OntologyEntityController_getEntityLinksByPrimaryKey`。
- 请求：**POST /ontology/entity/link**，Content-Type 为 `application/json`。
- 域配置：`DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`，按现有接口拼接上述路径。
- 接口实现：`src/apis/ontologyEntityApi.ts` 的 `postOntologyEntityLinksInterface`。
- 契约类型：`src/types/apis/postOntologyEntityLinksType.ts`；经 API / Types 公共出口使用。
- 使用位置：实例详情页现有关系图，以真实查询替换默认示例数据。
- 本次不生成额外 Mock；下述响应为按字段说明编写的演示样例，并非服务实测返回。

## 请求体 EntityQueryParam

| 字段                     | 类型             | 必填          | 说明                                                        |
| ------------------------ | ---------------- | ------------- | ----------------------------------------------------------- |
| ontologyUniqueIdentifier | string           | 否（OpenAPI） | 对象 ID；当前详情页始终传入，缺少时前端报错                 |
| entityPrimaryKey         | 未限制 JSON 类型 | 是            | 实体原始主键，不能用真假判断排除 0 或 false，不强制转字符串 |

```json
{
  "ontologyUniqueIdentifier": "object-a",
  "entityPrimaryKey": 0
}
```

本接口无分页参数，不传空间 ID。OpenAPI 未声明主键具体类型，客户端契约使用 unknown 接收原始值；详情页复用现有原始主键来源，缺少时按既有 instanceId 规则解析。

## 响应

标准响应 `RestResultListEntityLinkPropertyVO`：

| 字段    | 类型                   | 说明                             |
| ------- | ---------------------- | -------------------------------- |
| code    | integer(int32)         | 业务状态码，项目按 200 处理成功  |
| message | string                 | 返回消息，失败时展示             |
| data    | EntityLinkPropertyVO[] | 当前实例全部关联关系，非分页对象 |

### EntityLinkPropertyVO

OpenAPI 未将以下响应字段标为 required，前端均按可选字段处理。

| 字段                 | 类型               | 说明                                                                              |
| -------------------- | ------------------ | --------------------------------------------------------------------------------- |
| linkName             | string             | 关系名称                                                                          |
| linkType             | string 枚举        | COMPOSITION、RECONNAISSANCE、STRIKE、COORDINATION、OTHER、POSSESSION、ATTRIBUTION |
| ontologyFrom         | string             | 起点对象 ID                                                                       |
| ontologyTo           | string             | 终点对象 ID                                                                       |
| entityPrimaryKeyFrom | 未限制 JSON 类型   | 起点实例主键                                                                      |
| entityPrimaryKeyTo   | 未限制 JSON 类型   | 终点实例主键                                                                      |
| entityNodeFrom       | string             | 起点实例标识                                                                      |
| displayNameFrom      | string             | 起点实例显示名                                                                    |
| entityNodeTo         | string             | 终点实例标识                                                                      |
| displayNameTo        | string             | 终点实例显示名                                                                    |
| startTime            | string(date-time)  | 最近可见窗口开始时间                                                              |
| endTime              | string(date-time)  | 最近可见窗口结束时间                                                              |
| visibilityWindows    | VisibilityWindow[] | 可见窗口列表                                                                      |
| status               | string 枚举        | ENABLE、DISABLE、DELETE                                                           |

VisibilityWindow 包含可选的 `startTime`、`endTime`，均声明为 string(date-time)。但 OpenAPI 示例为 `"1769585745344"`，存在格式差异；本次保留原值，不擅自转日期。

## 页面映射与错误处理

- 请求随当前对象和实例切换；保留原始主键，进行中的同身份请求去重，旧请求及卸载后返回失效。
- 关系区独立处理加载、成功、空、失败与重试，不影响属性和行为区。
- data 为 null 按空兼容；非数组且非 null 的数据作为异常显示，不回退示例关系。
- 保留 From → To 方向。以对象与原始主键（缺失时用节点标识）识别端点，同名不同实例补充标识，平行边及自环保留。
- 关系名用作边标签，类型作为分类。接口未提供基数，现有只读图适配结构的 cardinality 仅作兼容占位，不展示或推断实际基数。
- 不擅自过滤 status，时间窗口保持原始契约，当前图不新增时间筛选交互。
- 无法确定端点身份的记录不生成虚构节点；全部无有效端点时显示暂无关联实体。
- 保留已有可选 relations 注入，普通页面默认使用接口数据；不触碰共享图组件的实例生命周期。
