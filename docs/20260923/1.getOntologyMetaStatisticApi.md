# 接口名称

- 统计本体对象关联的核心资源数量

## 编译位置

- apis：`src/apis/ontologyObjectManageApi.ts`
- types：`src/types/apis/getOntologyMetaStatisticType.ts`
- mocks：`src/mocks/getOntologyMetaStatisticMock/`

## 接口描述

- 统计本体对象关联的核心资源数量，包括实例、属性、关系和行为。
- 在线文档：本体对象管理 / `OntologyMetaController_getStatistic`。
- 响应模型描述为「本体对象资源统计」。
- OpenAPI 路径为 `/meta/statistic`，服务前缀为 `/ontology`。项目请求路径使用加前缀后的完整路径。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/meta/statistic`

## 请求方式

- GET

## 输入参数

- Query 参数，通过 URL 查询串传递。在线文档未给出默认值。

| 参数名           | 类型   | 必填 | 说明                                                 |
| ---------------- | ------ | ---- | ---------------------------------------------------- |
| uniqueIdentifier | string | 是   | 本体唯一标识。在线文档原文为「本体unique identifer」 |

请求示例：

```text
GET /ontology/meta/statistic?uniqueIdentifier=d3e1b0c27f29452eb7cadd1f51eac535
```

## 输出参数

在线文档的响应模型为 `RestResultOntologyMetaStatisticVO`。该操作只声明了 HTTP `200`。`OntologyMetaStatisticVO` 的属性均未标记 required。下面的取值只用于说明字段结构，不是文档给出的样例。

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "uniqueIdentifier": "d3e1b0c27f29452eb7cadd1f51eac535",
    "entityCount": 16,
    "propertyCount": 9,
    "relationCount": 4,
    "actionCount": 2
  }
}
```

顶层字段（`RestResult`）：

| 字段    | 类型                    | 说明     |
| ------- | ----------------------- | -------- |
| code    | integer / int32         | 响应码   |
| message | string                  | 消息描述 |
| data    | OntologyMetaStatisticVO | 统计数据 |

`data` 字段（`OntologyMetaStatisticVO`，本体对象资源统计）：

| 字段             | 类型            | 说明     |
| ---------------- | --------------- | -------- |
| uniqueIdentifier | string          | 本体 id  |
| entityCount      | integer / int32 | 实例数量 |
| propertyCount    | integer / int32 | 属性数量 |
| relationCount    | integer / int32 | 关系数量 |
| actionCount      | integer / int32 | 行为数量 |

## code

- 该操作在文档中声明的响应为 `200`。
- `code`、`message` 来自 `RestResult`，文档没有列出具体枚举值。

## message

- 文档只声明 `message` 为 string，没有给出固定文案。

## apis 示例

文件：`src/apis/ontologyObjectManageApi.ts`

```ts
import type { ApiResponse, GetOntologyMetaStatisticData, GetOntologyMetaStatisticParams } from "@/types";
import { request } from "@/utils/request";

/**
 * @description 统计本体对象关联的实例、属性、关系和行为数量。
 *
 * 请求方式：GET `/ontology/meta/statistic`
 *
 * @param params 查询参数。
 * @param params.uniqueIdentifier 本体唯一标识，必填。
 * @returns 标准 API 响应，data 为本体对象资源统计对象。
 */
export function getOntologyMetaStatisticInterface(params: GetOntologyMetaStatisticParams): Promise<ApiResponse<GetOntologyMetaStatisticData>> {
  return request<GetOntologyMetaStatisticData>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/meta/statistic",
    method: "get",
    params,
  });
}
```

并在 `src/apis/index.ts` 中导出：

```ts
export { getOntologyMetaStatisticInterface };
```
