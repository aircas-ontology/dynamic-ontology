# 接口名称

- 本体空间导入创建

## 编译位置

- apis：`src/apis/ontologyManageApi.ts`
- types：`src/types/apis/importOntologySpaceType.ts`
- mocks：`src/mocks/importOntologySpaceMock/`

## 接口描述

- 通过导入文件创建本体空间。
- 在线文档：本体空间管理 / `OntologySpaceController_importOntologySpace`。
- OpenAPI 路径为 `/space/import`，服务前缀为 `/ontology`。项目请求路径使用加前缀后的完整路径。
- 在线文档将请求内容标记为 `application/json`，但 `file` 为 binary 文件；实际上传必须使用 `multipart/form-data`，否则浏览器 `File` 对象不会作为文件内容提交。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/space/import`

## 请求方式

- POST

## 输入参数

- 请求体为 `multipart/form-data`。`file` 的 `format` 为 `binary`。在线文档未单独声明 multipart 类型，但文件上传按实际接口要求提交。

| 参数名 | 类型   | 必填 | 说明             |
| ------ | ------ | ---- | ---------------- |
| file   | binary | 是   | 本体空间导入文件 |

请求示例：

```text
POST /ontology/space/import
Content-Type: multipart/form-data

file: <binary file>
```

## 输出参数

在线文档的响应模型为 `RestResultListString`。该操作只声明了 HTTP `200`。`code`、`message`、`data` 均未标记 required，数组元素没有说明。下面的取值只用于说明字段结构，不是文档给出的样例。

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": ["imported-item"]
}
```

顶层字段（`RestResult`）：

| 字段    | 类型            | 说明       |
| ------- | --------------- | ---------- |
| code    | integer / int32 | 文档未说明 |
| message | string          | 文档未说明 |
| data    | array / string  | 文档未说明 |

`data` 的每一项都是 string。文档没有说明这些字符串表示空间 id、名称还是其他内容。

## code

- 该操作在文档中声明的响应为 `200`。
- `code` 来自 `RestResult`，文档没有列出具体枚举值。

## message

- 文档只声明 `message` 为 string，没有给出固定文案。

## apis 示例

文件：`src/apis/ontologyManageApi.ts`

请求体使用 `multipart/form-data`，通过 `FormData` 传递文件字段。

```ts
import type { ApiResponse, ImportOntologySpaceData, ImportOntologySpaceParams } from "@/types";
import { request } from "@/utils/request";

/**
 * @description 通过导入文件创建本体空间。
 *
 * 请求方式：POST `/ontology/space/import`
 *
 * @param params 请求参数。
 * @param params.file 导入文件，必填。
 * @returns 标准 API 响应，data 为字符串数组，元素含义以在线文档为准，文档未说明。
 */
export function postImportOntologySpaceInterface(params: ImportOntologySpaceParams): Promise<ApiResponse<ImportOntologySpaceData>> {
  const formData = new FormData();
  formData.append("file", params.file);
  return request<ImportOntologySpaceData>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/space/import",
    method: "post",
    data: formData,
    headers: { "Content-Type": "multipart/form-data" },
  });
}
```

并在 `src/apis/index.ts` 中导出：

```ts
export { postImportOntologySpaceInterface };
```
