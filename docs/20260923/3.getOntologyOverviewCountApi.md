# 接口名称

- 获取概览页面统计数据

## 编译位置

- apis：`src/apis/ontologyManageApi.ts`
- types：`src/types/apis/getOntologyOverviewCountType.ts`
- mocks：`src/mocks/getOntologyOverviewCountMock/`

## 接口描述

- 获取本体服务概览页面的资源数量统计，包括本体空间、本体、分组、行为调度、行为、函数、属性和关系数量。
- 在线文档：概览 / `OntologyOverviewController_getCount`。
- OpenAPI 路径为 `/overview/count`，服务前缀为 `/ontology`。项目请求路径使用加前缀后的完整路径。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/overview/count`

## 请求方式

- GET

## 输入参数

- 无 Query 参数。
- 无请求体。

请求示例：

```text
GET /ontology/overview/count
```

## 输出参数

在线文档响应模型为 `RestResultOverviewCountVO`，其中 `data` 类型为 `OverviewCountVO`。字段均未标记为必填，下面的示例来自在线文档的 200 响应示例。

```json
{
  "code": 0,
  "message": "",
  "data": {
    "spaceCount": 0,
    "ontologyCount": 0,
    "groupCount": 0,
    "actionSchedulingCount": 0,
    "actionCount": 0,
    "functionCount": 0,
    "propertyCount": 0,
    "linkCount": 0
  }
}
```

顶层字段（`RestResult`）：

| 字段    | 类型            | 必填 | 说明     |
| ------- | --------------- | ---- | -------- |
| code    | integer / int32 | 否   | 响应码   |
| message | string          | 否   | 消息描述 |
| data    | OverviewCountVO | 否   | 概览统计 |

`data` 字段（`OverviewCountVO`）：

| 字段                  | 类型            | 必填 | 说明         |
| --------------------- | --------------- | ---- | ------------ |
| spaceCount            | integer / int32 | 否   | 本体空间统计 |
| ontologyCount         | integer / int32 | 否   | 本体数量统计 |
| groupCount            | integer / int32 | 否   | 分组统计     |
| actionSchedulingCount | integer / int32 | 否   | 行为调度统计 |
| actionCount           | integer / int32 | 否   | 行为统计     |
| functionCount         | integer / int32 | 否   | 函数数量统计 |
| propertyCount         | integer / int32 | 否   | 本体属性统计 |
| linkCount             | integer / int32 | 否   | 本体关系统计 |

## code

- 在线文档仅声明 HTTP `200 OK`。
- 响应示例中的业务 `code` 为 `0`；文档没有提供更多 code 枚举说明。

## message

- 响应示例中的 `message` 为空字符串。
- 文档未声明固定成功或失败文案。

## apis 示例

文件：`src/apis/ontologyManageApi.ts`

```ts
import type { ApiResponse, GetOntologyOverviewCountData } from "@/types";
import { request } from "@/utils/request";

/**
 * @description 获取概览页面的本体空间、本体、分组、行为、函数、属性和关系统计数据。
 *
 * 请求方式：GET `/ontology/overview/count`
 *
 * @returns 标准 API 响应，data 为概览统计对象。
 */
export function getOntologyOverviewCountInterface(): Promise<ApiResponse<GetOntologyOverviewCountData>> {
  return request<GetOntologyOverviewCountData>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/overview/count",
    method: "get",
  });
}
```

并在 `src/apis/index.ts` 中导出：

```ts
export { getOntologyOverviewCountInterface } from "./ontologyManageApi";
```
