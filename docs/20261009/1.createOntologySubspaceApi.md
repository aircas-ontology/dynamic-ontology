# 接口名称

- 基于父空间创建子空间

## 编译位置

- apis：`src/apis/ontologyManageApi.ts`
- types：`src/types/apis/createOntologySubspaceType.ts`
- mocks：`src/mocks/createOntologySubspaceMock/`

## 接口描述

- 基于父空间勾选的对象、实例、属性和关系创建子空间。
- 在线文档：本体空间管理 / `OntologySpaceController_createSubspace`。
- 请求模型为 `OntologySubspaceCreateParam`，响应模型为 `RestResultOntologySubspaceCreateVO`。
- OpenAPI 路径为 `/space/subspace`，服务前缀为 `/ontology`。项目请求路径使用加前缀后的完整路径。
- 请求体为 `application/json`。

## 接口 domain

- `DOMAIN_CONFIG.ONTOLOGYMANAGE_URL`

## 接口 uri

- `/ontology/space/subspace`

## 请求方式

- POST

## 输入参数

- 请求体 JSON，对应 `OntologySubspaceCreateParam`。在线文档未给出默认值。
- 入参样例来自调用方提供的请求体；字段说明来自在线文档。

顶层字段（`OntologySubspaceCreateParam`，创建子空间请求）：

| 参数名             | 类型                                  | 必填 | 说明                |
| ------------------ | ------------------------------------- | ---- | ------------------- |
| parentSpaceId      | integer / int32                       | 是   | 父空间 id（源空间） |
| displayName        | string，minLength 1                   | 是   | 子空间显示名称      |
| apiName            | string，minLength 1                   | 是   | 子空间 api 名称     |
| description        | string                                | 否   | 子空间描述          |
| iconUrl            | string                                | 否   | 子空间图标 url      |
| selectedOntologies | array / OntologySelection，minItems 1 | 是   | 选中的对象配置      |
| selectedLinks      | array / LinkSelection                 | 否   | 选中的关系配置      |

`selectedOntologies[]`（`OntologySelection`，选中的本体对象）：

| 参数名                         | 类型                                  | 必填 | 说明                                                           |
| ------------------------------ | ------------------------------------- | ---- | -------------------------------------------------------------- |
| sourceOntologyUniqueIdentifier | string，minLength 1                   | 是   | 源空间中被选中的本体 uniqueIdentifier                          |
| selectedInstancePrimaryKeys    | array                                 | 否   | 显式勾选的实例主键列表；为空表示按属性筛选条件导入全部匹配实例 |
| selectedProperties             | array / PropertySelection，minItems 1 | 是   | 选中的属性及筛选条件                                           |

`selectedInstancePrimaryKeys` 的 OpenAPI `items` 未声明类型。调用方入参样例为整数主键，例如 `1`、`2`、`3`。

`selectedProperties[]`（`PropertySelection`，选中的属性及筛选条件）：

| 参数名                         | 类型                 | 必填 | 说明                                  |
| ------------------------------ | -------------------- | ---- | ------------------------------------- |
| sourcePropertyUniqueIdentifier | string，minLength 1  | 是   | 源空间中被选中的属性 uniqueIdentifier |
| filter                         | PropertyFilterConfig | 否   | 属性筛选条件；不配置筛选时传 `null`   |

`filter`（`PropertyFilterConfig`，属性筛选条件）：

| 参数名   | 类型       | 必填 | 说明                                                                                                                                                                                                                                         |
| -------- | ---------- | ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| op       | string     | 是   | 筛选操作符。枚举：`EQ`、`NE`、`LIKE`、`LIKE_LEFT`、`LIKE_RIGHT`、`IN`、`NOT_IN`、`BETWEEN`、`NOT_BETWEEN`、`GT`、`GE`、`LT`、`LE`、`IS_NULL`、`IS_NOT_NULL`、`APPLY`                                                                         |
| value    | 未声明类型 | 否   | 筛选值：单值 op（EQ/LIKE/GT 等）传标量，如 `"驱逐舰"` 或 `3000`；多值 op（IN/BETWEEN 等）传数组，如 `["福特","通用"]` 或 `[3000,10000]`（BETWEEN 约定 `[lower, upper]`）。统一用本字段，不再有 values 字段                                   |
| dataType | string     | 是   | 属性数据类型。枚举：`Bool`、`Int`、`Long`、`Float`、`Short`、`Byte`、`Double`、`Decimal`、`String`、`Date`、`Array`、`Map`、`Vector`、`Timestamp`、`MediaReference`、`TimeSeries`、`Attachment`、`Geohash`、`Geoshape`、`Cipher`、`Ontology` |

`selectedLinks[]`（`LinkSelection`，选中的关系）：

| 参数名                     | 类型                | 必填 | 说明                                                                                                       |
| -------------------------- | ------------------- | ---- | ---------------------------------------------------------------------------------------------------------- |
| sourceLinkUniqueIdentifier | string，minLength 1 | 是   | 源空间中被选中的关系 uniqueIdentifier                                                                      |
| name                       | string              | 否   | 新关系名称；为空则沿用源关系名称                                                                           |
| apiName                    | string              | 否   | 新关系 api 名称；为空则自动生成                                                                            |
| type                       | string              | 否   | 新关系类型；为空则沿用源关系类型。枚举：`COMPOSITION`、`RECONNAISSANCE`、`STRIKE`、`COORDINATION`、`OTHER` |
| description                | string              | 否   | 新关系描述                                                                                                 |

## 输出参数

在线文档的响应模型为 `RestResultOntologySubspaceCreateVO`。该操作只声明了 HTTP `200`。`code`、`message`、`data` 及 `OntologySubspaceCreateVO` 的属性均未标记 required。下面的取值只用于说明字段结构，不是文档给出的样例。

```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": {
    "spaceId": 108,
    "ontologyMapping": {
      "777df6b054504cf590aecc844b5fafb4": "new-ontology-id-1",
      "d0f6090aa12640d4ad846b0efcd21eca": "new-ontology-id-2"
    },
    "linkMapping": {
      "1a5af100358e48368a0ca64520789eef": "new-link-id-1"
    }
  }
}
```

顶层字段（`RestResult`）：

| 字段    | 类型                     | 说明           |
| ------- | ------------------------ | -------------- |
| code    | integer / int32          | 响应码         |
| message | string                   | 消息描述       |
| data    | OntologySubspaceCreateVO | 子空间创建结果 |

`data` 字段（`OntologySubspaceCreateVO`，子空间创建结果）：

| 字段            | 类型                                 | 说明                                                    |
| --------------- | ------------------------------------ | ------------------------------------------------------- |
| spaceId         | integer / int32                      | 新建子空间 id                                           |
| ontologyMapping | object / additionalProperties string | 源本体 uniqueIdentifier -> 新本体 uniqueIdentifier 映射 |
| linkMapping     | object / additionalProperties string | 源关系 uniqueIdentifier -> 新关系 uniqueIdentifier 映射 |

## code

- 该操作在文档中声明的响应为 `200`。
- `code`、`message` 来自 `RestResult`，文档没有列出具体枚举值。

## message

- 文档只声明 `message` 为 string，没有给出固定文案。

## apis 示例

```ts
import type { ApiResponse, CreateOntologySubspaceData, CreateOntologySubspaceParams } from "@/types";
import { request } from "@/utils/request";

/**
 * @description 基于父空间勾选的对象、实例、属性和关系创建子空间。
 *
 * 请求方式：POST `/ontology/space/subspace`
 *
 * @param params 创建子空间请求体。
 * @param params.parentSpaceId 父空间 id，必填。
 * @param params.displayName 子空间显示名称，必填。
 * @param params.apiName 子空间 api 名称，必填。
 * @param params.selectedOntologies 选中的对象配置，必填。
 * @returns 标准 API 响应，data 为子空间创建结果。
 */
export function createOntologySubspaceInterface(params: CreateOntologySubspaceParams): Promise<ApiResponse<CreateOntologySubspaceData>> {
  return request<CreateOntologySubspaceData>({
    url: DOMAIN_CONFIG.ONTOLOGYMANAGE_URL + "/ontology/space/subspace",
    method: "post",
    data: params,
  });
}
```
