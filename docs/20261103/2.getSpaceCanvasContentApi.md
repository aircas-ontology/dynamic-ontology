# 查询对象空间画布内容

## 接口信息

| 项目         | 内容                                            |
| ------------ | ----------------------------------------------- |
| 接口名称     | 查询画布内容                                    |
| 业务域       | 对象空间管理                                    |
| 请求方法     | `GET`                                           |
| 请求路径     | `/ontology/space/canvas`                        |
| Operation ID | `OntologySpaceController_getSpaceCanvasContent` |
| 接口说明     | 返回空间下的全部对象、对象属性和对象关系        |

接口返回的数据结构与 `POST /space/canvas` 的请求体相同，前端可直接用于画布渲染，编辑后也可回传保存。

## 请求参数

参数通过查询字符串传递。

| 参数名    | 类型             | 必填 | 说明        | 示例 |
| --------- | ---------------- | ---- | ----------- | ---- |
| `spaceId` | `integer(int32)` | 是   | 对象空间 ID | `1`  |

请求示例：

```http
GET /ontology/space/canvas?spaceId=1 HTTP/1.1
Accept: application/json
```

## 响应结构

HTTP 状态码为 `200` 时，响应包裹结构如下：

| 字段名    | 类型                             | 说明       |
| --------- | -------------------------------- | ---------- |
| `code`    | `integer(int32)`                 | 业务状态码 |
| `message` | `string`                         | 返回消息   |
| `data`    | `OntologySpaceCanvasCreateParam` | 画布内容   |

### `data` 画布内容

| 字段名       | 类型               | 必填 | 说明                                                                  |
| ------------ | ------------------ | ---- | --------------------------------------------------------------------- |
| `spaceId`    | `integer(int32)`   | 否   | 对象空间 ID。返回数据中表示当前空间；该字段用于 POST 时指定已有空间。 |
| `ontologies` | `CanvasOntology[]` | 否   | 画布中的对象列表                                                      |
| `links`      | `CanvasLink[]`     | 否   | 画布中的关系列表                                                      |

### `ontologies[]` 画布对象

| 字段名        | 类型               | 必填 | 说明                                                    | 示例      |
| ------------- | ------------------ | ---- | ------------------------------------------------------- | --------- |
| `displayName` | `string`           | 是   | 对象名称                                                | `舰船aaa` |
| `apiName`     | `string`           | 是   | 对象 API 名称；格式为 `^[a-zA-Z_$][a-zA-Z0-9_$]{0,62}$` | `ship`    |
| `description` | `string`           | 否   | 对象描述                                                |           |
| `iconUrl`     | `string`           | 否   | 对象图标 URL                                            |           |
| `properties`  | `CanvasProperty[]` | 否   | 对象属性列表                                            |           |

### `ontologies[].properties[]` 画布对象属性

| 字段名         | 类型      | 必填 | 说明                                                    | 示例     |
| -------------- | --------- | ---- | ------------------------------------------------------- | -------- |
| `displayName`  | `string`  | 是   | 属性展示名称                                            | `名称`   |
| `apiName`      | `string`  | 是   | 属性 API 名称；格式为 `^[a-zA-Z_$][a-zA-Z0-9_$]{0,62}$` | `name`   |
| `dataType`     | `string`  | 否   | 数据类型，不传时默认为 `String`                         | `String` |
| `storageGroup` | `string`  | 否   | 存储分组                                                | `String` |
| `description`  | `string`  | 否   | 属性描述                                                |          |
| `isPrimaryKey` | `boolean` | 否   | 是否为主键，不传时默认为 `false`                        | `false`  |
| `isTitleKey`   | `boolean` | 否   | 是否为名称键，不传时默认为 `false`                      | `false`  |
| `defaultValue` | `string`  | 否   | 属性默认值                                              |          |

`dataType` 可选值：`Bool`、`Int`、`Long`、`Float`、`Short`、`Byte`、`Double`、`Decimal`、`String`、`Date`、`Array`、`Map`、`Vector`、`Timestamp`、`MediaReference`、`TimeSeries`、`Attachment`、`Geohash`、`Geoshape`、`Cipher`、`Ontology`。

### `links[]` 画布对象关系

| 字段名                | 类型     | 必填 | 说明                                    | 示例      |
| --------------------- | -------- | ---- | --------------------------------------- | --------- |
| `name`                | `string` | 是   | 关系名称                                | `隶属于`  |
| `apiName`             | `string` | 否   | 关系 API 名称，预留字段，当前不落库     | `lishuyu` |
| `description`         | `string` | 否   | 关系描述，预留字段，当前不落库          |           |
| `fromOntologyApiName` | `string` | 是   | 源对象 API 名称，也兼容传对象显示名称   | `ship`    |
| `toOntologyApiName`   | `string` | 是   | 目标对象 API 名称，也兼容传对象显示名称 | `country` |
