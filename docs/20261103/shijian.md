# 创建行为业务逻辑

# 基础行为（类别）

限制要求：
不管基础操作是新增修改还是删除，选择的属性都只能来自同一个分组

# 基础行为（类别）-属性值（行为类型）-新增（基础操作）

限制要求：
1新增时不能选择存储分组为main的属性
2新增时选择某一分组的单个属性要全选分组的其他属性

# 基础行为（类别）-属性值（行为类型）-修改（基础操作）

限制要求：
1修改可以选择某个分组的单个或多个属性

# 基础行为（类别）-属性值（行为类型）-删除（基础操作）

限制要求：
1删除时不能选择存储分组为main的属性
2删除除了main分组的其他分组属性时，选一个属性要全选该分组的其他属性
