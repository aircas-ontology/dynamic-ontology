# 空天 · 灵枢--动态本体（前端）

## 1、基本介绍

- 基于 vite vue3 开发 web 应用
- 当前版本为 v0.1.0

## 2、开发手册

- node：v22.19.0 及以上
- chrome：110以上

## 3、运行

```sh
npm install
npm run dev
npm run build 打包部署
```
